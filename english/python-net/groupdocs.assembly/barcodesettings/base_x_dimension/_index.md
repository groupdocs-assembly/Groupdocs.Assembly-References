## base_x_dimension property

The base x-dimension, the smallest width of the unit of barcode bars and spaces, measured in [`BarcodeSettings.graphics_unit`](/assembly/python-net/groupdocs.assembly/barcodesettings/graphics_unit/).

When barcode scaling is applied through a template, an actual x-dimension is calculated from the base x-dimension and a scaling factor.

## KnownTypeSet class

Represents an unordered set of unique `type` objects whose fully or partially qualified names can be used within document templates to invoke static members, perform type casts, etc.

This class is just a facade of `Aspose.Reporting.KnownTypeSetCore`. Descriptional comments of these classes should be kept in sync.

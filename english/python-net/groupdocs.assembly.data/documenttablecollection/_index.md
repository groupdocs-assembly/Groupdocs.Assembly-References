## DocumentTableCollection class

Represents a read‑only collection of [`DocumentTable`](/assembly/python-net/groupdocs.assembly.data/documenttable/) objects of a particular [`DocumentTableSet`](/assembly/python-net/groupdocs.assembly.data/documenttableset/) instance.

The collection is filled automatically while loading the corresponding tables from a document and cannot be modified. However, properties of [`DocumentTable`](/assembly/python-net/groupdocs.assembly.data/documenttable/) objects contained within the collection can be modified.

The DocumentTableCollection type exposes the following members:

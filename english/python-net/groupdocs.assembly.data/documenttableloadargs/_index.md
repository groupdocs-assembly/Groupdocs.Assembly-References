## DocumentTableLoadArgs class

Provides data for the [`IDocumentTableLoadHandler.handle`](/assembly/python-net/groupdocs.assembly.data/idocumenttableloadhandler/handle/) method.

GroupDocs.Assembly for Python via .NET API provides the ability to load multiple DocumentTable objects from a single file as a single operation.

The DocumentTableLoadArgs type exposes the following members:

### Properties
| Property | Description |
| :- | :- |
| [is_loaded](/assembly/python-net/groupdocs.assembly.data/documenttableloadargs/is_loaded/) | The flag indicating whether the corresponding document table should be loaded. The default value is True. |
| [options](/assembly/python-net/groupdocs.assembly.data/documenttableloadargs/options/) | The DocumentTableOptions to be used while loading the corresponding document table. The default value is None, which means that default DocumentTableOptions are applied. |
| [table_index](/assembly/python-net/groupdocs.assembly.data/documenttableloadargs/table_index/) | The zero-based index of the document table to be loaded. |

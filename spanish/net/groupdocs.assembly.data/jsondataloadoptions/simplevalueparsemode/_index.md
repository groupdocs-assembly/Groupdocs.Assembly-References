## JsonDataLoadOptions.SimpleValueParseMode property

Obtiene o establece un modo para analizar valores simples JSON (null, booleano, número, entero y cadena) al cargar JSON. Ese modo no afecta el análisis de valores de fecha y hora. El valor predeterminado es Loose.

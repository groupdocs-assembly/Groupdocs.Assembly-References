## DocumentTableOptions.FirstRowContainsColumnNames property

Obtiene o establece un valor que indica si los nombres de columna deben obtenerse de la primera fila extraída de una tabla de documento. El valor predeterminado es false.

```csharp
public bool FirstRowContainsColumnNames { get; set; }
```

### Observaciones

Si los nombres de columna no se configuran para obtenerse de la primera fila extraída de una tabla de documento, se utilizan los nombres de columna predeterminados. Para documentos de formatos de archivo de hoja de cálculo, los nombres de columna predeterminados se definen como A, B, C, ... Z, AA, AB, etc. Para documentos de otros formatos de archivo, los nombres de columna predeterminados se definen como Column1, Column2, Column3, etc.

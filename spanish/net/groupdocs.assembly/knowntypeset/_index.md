## KnownTypeSet class

Representa un conjunto no ordenado (es decir, una colección de elementos únicos) que contiene objetos Type cuyos nombres totalmente o parcialmente calificados pueden usarse dentro de plantillas de documentos para invocar los miembros estáticos de los tipos correspondientes, realizar conversiones de tipo, etc.

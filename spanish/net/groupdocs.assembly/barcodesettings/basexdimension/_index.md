## BarcodeSettings.BaseXDimension property

Obtiene o establece una dimensión x base, es decir, el ancho más pequeño de la unidad de barras y espacios del código de barras. Medido en [`GraphicsUnit`](../graphicsunit).

```csharp
public float BaseXDimension { get; set; }
```

### Observaciones

Cuando se aplica el escalado del código de barras a través de una plantilla, se calcula una dimensión x real a partir de la dimensión x base y un factor de escala.

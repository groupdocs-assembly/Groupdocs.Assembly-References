## BarcodeSettings.UseAutoCorrection property

Obtiene o establece un valor que indica si un valor de código de barras inválido debe corregirse automáticamente (si es posible) para ajustarse a la especificación del código de barras o si se debe lanzar una excepción para indicar el error. El valor predeterminado es true.

```csharp
public bool UseAutoCorrection { get; set; }
```

### Observaciones

La autocorrección no es posible para los códigos de barras Databar.

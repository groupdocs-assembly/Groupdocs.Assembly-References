## XmlDataLoadOptions.AlwaysGenerateRootObject property

Ottiene o imposta un flag che indica se una data source generata conterrà sempre un oggetto per un elemento radice XML. Se un elemento radice XML non ha attributi e tutti i suoi elementi figlio hanno lo stesso nome, tale oggetto non viene creato per impostazione predefinita.

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### Osservazioni

Il valore predefinito è **false**.

## DocumentTableColumn.Type property

Ottiene o imposta il tipo di valori delle celle in questa colonna.

```csharp
public Type Type { get; set; }
```

### Osservazioni

Per i documenti di formati non Spreadsheet, il tipo iniziale è sempre determinato automaticamente come stringa. Per i documenti di formati Spreadsheet, il tipo iniziale è determinato automaticamente in base ai valori delle celle corrispondenti.

Se le celle di una specifica colonna Spreadsheet contengono valori di tipi diversi, anche il tipo iniziale della colonna viene determinato automaticamente come stringa.

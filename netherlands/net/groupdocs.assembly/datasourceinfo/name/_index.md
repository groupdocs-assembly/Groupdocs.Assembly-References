## DataSourceInfo.Name property

Haalt op of stelt de naam van het gegevensbronobject in die gebruikt wordt om toegang te krijgen tot het gegevensbronobject in een sjabloondocument.

```csharp
public string Name { get; set; }
```

### Opmerkingen

Wanneer de naam van het gegevensbronobject is opgegeven, kun je het gegevensbronobject en zijn leden in een sjabloondocument benaderen met behulp van de naam.

Wanneer de naam van het gegevensbronobject null of leeg is, kun je nog steeds leden van het gegevensbronobject in een sjabloondocument benaderen via contextobject-lidtoegang (zie Template Syntax Reference voor meer informatie), maar je kunt het gegevensbronobject zelf niet benaderen.

Wanneer je meerdere [`DataSourceInfo`](../../datasourceinfo)-instanties doorgeeft aan [`DocumentAssembler`](../../documentassembler), mag alleen de naam van het eerste gegevensbronobject null of leeg zijn. De namen van de overige moeten worden opgegeven en uniek zijn.

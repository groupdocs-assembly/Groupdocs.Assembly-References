## DataSourceInfo(object, string) {#constructor_2}


| Parameter | Type | Beschrijving |
| --- | --- | --- |
| dataSource | Object | Het gegevensbronobject. |
| name | String | De naam van het gegevensbronobject dat moet worden gebruikt om toegang te krijgen tot het gegevensbronobject in een sjabloondocument. |

### Opmerkingen

Het gegevensbronobject kan een van de volgende types zijn:

* [`XmlDataSource`](../../../groupdocs.assembly.data/xmldatasource)
* [`JsonDataSource`](../../../groupdocs.assembly.data/jsondatasource)
* [`CsvDataSource`](../../../groupdocs.assembly.data/csvdatasource)
* [`DocumentTableSet`](../../../groupdocs.assembly.data/documenttableset)
* [`DocumentTable`](../../../groupdocs.assembly.data/documenttable)
* DataSet
* DataTable
* DataRow
* IDataReader
* IDataRecord
* DataView
* DataRowView
* Any other arbitrary non-dynamic and non-anonymous .NET type

Voor informatie over hoe je met gegevensbronnen van verschillende types in sjabloondocumenten werkt, zie de template syntax reference (https://docs.groupdocs.com/display/assemblynet/Template+Syntax+-+Part+1+of+2#TemplateSyntax-Part1of2-UsingDataSources).

Wanneer de naam van het gegevensbronobject is opgegeven, kun je het gegevensbronobject en zijn leden in een sjabloondocument benaderen met behulp van de naam.

Wanneer de naam van het gegevensbronobject null of leeg is, kun je nog steeds leden van het gegevensbronobject in een sjabloondocument benaderen via contextobject-lidtoegang (zie Template Syntax Reference voor meer informatie), maar je kunt het gegevensbronobject zelf niet benaderen.

Wanneer je meerdere [`DataSourceInfo`](../../datasourceinfo)-instanties doorgeeft aan [`DocumentAssembler`](../../documentassembler), mag alleen de naam van het eerste gegevensbronobject null of leeg zijn. De namen van de overige moeten worden opgegeven en uniek zijn.

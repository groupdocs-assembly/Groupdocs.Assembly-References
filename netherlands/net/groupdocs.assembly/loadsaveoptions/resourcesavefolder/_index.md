## LoadSaveOptions.ResourceSaveFolder property

Krijgt of stelt een pad in naar een map om externe hulpbronbestanden op te slaan terwijl een samengesteld document, geladen uit een niet‑HTML‑formaat, wordt opgeslagen als HTML. De standaardwaarde is een lege tekenreeks.

```csharp
public string ResourceSaveFolder { get; set; }
```

### Opmerkingen

Standaard, wanneer een samengesteld document wordt opgeslagen naar een HTML‑bestand, worden externe hulpbronbestanden opgeslagen in een map met dezelfde naam als het HTML‑bestand zonder extensie, aangevuld met de suffix "_files". Deze map bevindt zich in dezelfde map als het HTML‑bestand. Dit kan echter niet worden gedaan bij het opslaan van een samengesteld document naar een HTML‑stream. Stel deze eigenschap in om een pad op te geven naar een map om externe hulpbronbestanden op te slaan bij het opslaan van een samengesteld document naar een HTML‑stream, of om de standaardmap te overschrijven bij het opslaan van een samengesteld document naar een HTML‑bestand.

Een waarde van deze eigenschap wordt genegeerd als een samengesteld document dat naar HTML wordt opgeslagen, ook vanuit HTML is geladen (externe hulpbronbestanden worden dan niet opgeslagen en de koppelingen ernaar worden niet aangepast).

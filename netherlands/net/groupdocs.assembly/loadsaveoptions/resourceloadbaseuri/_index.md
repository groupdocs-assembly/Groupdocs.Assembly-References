## LoadSaveOptions.ResourceLoadBaseUri property

Krijgt of stelt een basis‑URI in om relatieve URI's van externe hulpbronbestanden om te zetten naar absolute URI's tijdens het laden van een HTML‑sjabloondocument dat moet worden samengesteld en opgeslagen in een niet‑HTML‑formaat. De standaardwaarde is een lege tekenreeks.

```csharp
public string ResourceLoadBaseUri { get; set; }
```

### Opmerkingen

Bij het laden van een HTML‑document vanuit een bestand wordt de map waarin het zich bevindt standaard als basis‑URI gebruikt, wat niet kan gebeuren bij het laden van een HTML‑document vanuit een stroom. Stel deze eigenschap in om een basis‑URI op te geven bij het laden van een HTML‑document vanuit een stroom of om de standaard basis‑URI te overschrijven bij het laden van een HTML‑document vanuit een bestand.

Een waarde van deze eigenschap wordt genegeerd in de volgende gevallen:

* An HTML document being loaded contains a BASE HTML element providing a base URI.
* An HTML document being loaded is to be assembled and saved to HTML (external resource files are not loaded and relative URIs are not changed then).

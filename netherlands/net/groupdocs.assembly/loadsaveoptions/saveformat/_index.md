## LoadSaveOptions.SaveFormat property

Krijgt of stelt een bestandsformaat in om een samengesteld document in op te slaan. Niet gespecificeerd is de standaard.

```csharp
public FileFormat SaveFormat { get; set; }
```

### Opmerkingen

Wanneer de waarde van deze eigenschap niet is opgegeven, gedraagt [`DocumentAssembler`](../../documentassembler) zich als volgt:

- When you specify a file path to save an assembled document, the save file format is determined upon file extension from the path.

- When you specify a stream to save an assembled document, the save file format remains the same as the file format of a loaded template document.

Wees ervan bewust dat het niet altijd mogelijk is om een samengesteld document op te slaan in elk bestandsformaat met GroupDocs.Assembly. Bijvoorbeeld, het is onmogelijk om een document dat is geladen vanuit een tekstverwerkingsformaat (zoals DOCX) op te slaan in een spreadsheet‑formaat (zoals XLSX). Voor meer informatie over mogelijke combinaties van laad‑ en opslag‑bestandsformaten die door GroupDocs.Assembly worden ondersteund, raadpleeg de online documentatie van GroupDocs.Assembly.

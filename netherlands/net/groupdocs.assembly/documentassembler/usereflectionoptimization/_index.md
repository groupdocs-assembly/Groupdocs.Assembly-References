## DocumentAssembler.UseReflectionOptimization property

Krijgt of stelt een waarde in die aangeeft of aanroepen van aangepaste type‑leden uitgevoerd via de reflection‑API geoptimaliseerd zijn met dynamische klasse‑generatie of niet. De standaardwaarde is true.

```csharp
public static bool UseReflectionOptimization { get; set; }
```

### Opmerkingen

Er zijn enkele scenario's waarin het beter is deze optimalisatie uit te schakelen. Bijvoorbeeld, als u voortdurend met kleine collecties gegevensitems werkt, kan de overhead van dynamische klassegeneratie opvallender zijn dan de overhead van directe reflectie‑API‑aanroepen.

## DocumentTableOptions.FirstRowContainsColumnNames property

Haalt op of stelt een waarde in die aangeeft of kolomnamen moeten worden verkregen uit de eerste geëxtraheerde rij van een documenttabel. De standaardwaarde is false.

```csharp
public bool FirstRowContainsColumnNames { get; set; }
```

### Opmerkingen

Als kolomnamen niet worden ingesteld om te worden verkregen uit de eerst geëxtraheerde rij van een documenttabel, worden standaardkolomnamen gebruikt. Voor documenten van spreadsheet-bestandsformaten worden standaardkolomnamen gedefinieerd als A, B, C, ... Z, AA, AB, enzovoort. Voor documenten van andere bestandsformaten worden standaardkolomnamen gedefinieerd als Column1, Column2, Column3, enzovoort.

## DocumentTable.Name property

Geeft of stelt de naam van deze tabel in die wordt gebruikt om de gegevens van de tabel te benaderen in een sjabloondocument dat wordt doorgegeven aan [`DocumentAssembler`](../../../groupdocs.assembly/documentassembler).

```csharp
public string Name { get; set; }
```

### Opmerkingen

Als de naam van de tabel uit een document wordt gelezen, wordt de naam automatisch gecorrigeerd zodat deze geldig is. Als de naam van de tabel echter handmatig via deze eigenschap wordt ingesteld en de naam ongeldig is, wordt er een uitzondering gegooid.

De naam van de tabel wordt als geldig beschouwd als aan de volgende voorwaarden wordt voldaan:

* The name is not empty.
* The name's first character is a letter or underscore.
* The rest of the name's characters are letters, underscores, digits, or the following characters: '@', '#', '$'.
* The corresponding [`DocumentTableSet`](../../documenttableset) object does not contain a [`DocumentTable`](../../documenttable) instance with the same name.

## JsonSimpleValueParseMode enumeration

Specificeert een modus voor het parseren van eenvoudige JSON‑waarden (null, boolean, getal, integer en string) tijdens het laden van JSON. Een dergelijke modus heeft geen invloed op het parseren van datum‑tijdwaarden.

```csharp
public enum JsonSimpleValueParseMode
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Loose | `0` | Specificeert de modus waarbij de typen van eenvoudige JSON‑waarden worden bepaald bij het parseren van hun tekenreeksrepresentaties. Bijvoorbeeld, het type van 'prop' uit het JSON‑fragment '{ prop: \"123\" }' wordt in deze modus als integer bepaald. |
| Strict | `1` | Specificeert de modus waarbij de typen van eenvoudige JSON‑waarden worden bepaald aan de hand van de JSON‑notatie zelf. Bijvoorbeeld, het type van 'prop' uit het JSON‑fragment '{ prop: \"123\" }' wordt in deze modus als string bepaald. |

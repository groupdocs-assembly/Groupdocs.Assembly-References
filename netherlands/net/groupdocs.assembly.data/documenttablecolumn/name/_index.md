## DocumentTableColumn.Name property

Haalt de naam van deze kolom op of stelt deze in, die wordt gebruikt om de gegevens van de kolom te benaderen in een sjabloondocument dat wordt doorgegeven aan [`DocumentAssembler`](../../../groupdocs.assembly/documentassembler).

```csharp
public string Name { get; set; }
```

### Opmerkingen

Als de naam van de kolom uit een document wordt gelezen (zie [`FirstRowContainsColumnNames`](../../documenttableoptions/firstrowcontainscolumnnames)), wordt de naam automatisch gecorrigeerd zodat deze geldig is. Als de naam van de kolom echter handmatig via deze eigenschap wordt ingesteld en de naam ongeldig is, wordt er een uitzondering gegooid.

De naam van de kolom wordt als geldig beschouwd als aan de volgende voorwaarden wordt voldaan:

* The name is not empty.
* The name's first character is a letter or underscore.
* The rest of the name's characters are letters, underscores, digits, or the following characters: '@', '#', '$'.
* The corresponding [`DocumentTable`](../../documenttable) object does not contain a [`DocumentTableColumn`](../../documenttablecolumn) instance with the same name.

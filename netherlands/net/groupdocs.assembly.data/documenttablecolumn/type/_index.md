## DocumentTableColumn.Type property

Haalt het type van celwaarden in deze kolom op of stelt dit in.

public Type Type { get; set; }

### Opmerkingen

Voor documenten met niet-Spreadsheet bestandsformaten wordt het initiële type altijd automatisch bepaald als string. Voor documenten met Spreadsheet bestandsformaten wordt het initiële type automatisch bepaald op basis van de overeenkomstige celwaarden.

Als cellen van een specifieke Spreadsheet-kolom waarden van verschillende typen bevatten, wordt het initiële type van de kolom ook automatisch bepaald als string.

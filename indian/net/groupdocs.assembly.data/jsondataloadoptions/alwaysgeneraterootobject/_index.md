## JsonDataLoadOptions.AlwaysGenerateRootObject property

एक फ़्लैग प्राप्त करता है या सेट करता है जो यह दर्शाता है कि क्या उत्पन्न डेटा स्रोत हमेशा एक JSON रूट तत्व के लिए एक वस्तु रखेगा। यदि एक JSON रूट तत्व में एक ही जटिल प्रॉपर्टी है, तो ऐसी वस्तु डिफ़ॉल्ट रूप से नहीं बनाई जाती।

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### टिप्पणियाँ

डिफ़ॉल्ट मान **false** है।

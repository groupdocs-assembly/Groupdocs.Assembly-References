## XmlDataLoadOptions.AlwaysGenerateRootObject property

एक फ़्लैग प्राप्त करता है या सेट करता है जो यह दर्शाता है कि क्या उत्पन्न डेटा स्रोत हमेशा एक XML रूट तत्व के लिए एक वस्तु रखेगा। यदि एक XML रूट तत्व में कोई एट्रिब्यूट नहीं है और सभी चाइल्ड तत्वों के नाम समान हैं, तो ऐसी वस्तु डिफ़ॉल्ट रूप से नहीं बनाई जाती।

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### टिप्पणियाँ

डिफ़ॉल्ट मान **false** है।

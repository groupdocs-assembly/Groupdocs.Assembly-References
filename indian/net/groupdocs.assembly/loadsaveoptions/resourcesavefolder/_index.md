## LoadSaveOptions.ResourceSaveFolder property

एक फ़ोल्डर का पथ प्राप्त करता है या सेट करता है जहाँ बाहरी संसाधन फ़ाइलें संग्रहीत की जाएँगी, जबकि गैर-HTML फ़ॉर्मेट से लोड किया गया असेंबल किया गया दस्तावेज़ HTML में सहेजा जा रहा हो। डिफ़ॉल्ट मान एक खाली स्ट्रिंग है।

```csharp
public string ResourceSaveFolder { get; set; }
```

### टिप्पणियाँ

डिफ़ॉल्ट रूप से, जब एक असेंबल्ड दस्तावेज़ को HTML फ़ाइल में सहेजा जाता है, तो बाहरी संसाधन फ़ाइलें उसी नाम वाले फ़ोल्डर में संग्रहीत होती हैं जिसमें HTML फ़ाइल का एक्सटेंशन नहीं होता और उसके बाद "_files" उपसर्ग जुड़ता है। यह फ़ोल्डर HTML फ़ाइल के समान फ़ोल्डर में स्थित होता है। हालांकि, यह HTML स्ट्रीम में असेंबल्ड दस्तावेज़ को सहेजते समय संभव नहीं है। इस प्रॉपर्टी को सेट करके आप HTML स्ट्रीम में असेंबल्ड दस्तावेज़ को सहेजते समय बाहरी संसाधन फ़ाइलों के लिए फ़ोल्डर पथ निर्दिष्ट कर सकते हैं या HTML फ़ाइल में सहेजते समय डिफ़ॉल्ट फ़ोल्डर को ओवरराइड कर सकते हैं।

इस प्रॉपर्टी का मान अनदेखा किया जाता है यदि HTML में सहेजा जा रहा असेंबल्ड दस्तावेज़ को उसी HTML से लोड किया गया हो (बाहरी संसाधन फ़ाइलें संग्रहीत नहीं होतीं और उनके लिंक भी नहीं बदले जाते)।

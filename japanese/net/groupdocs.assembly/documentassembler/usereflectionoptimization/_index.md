## DocumentAssembler.UseReflectionOptimization property

カスタム型メンバーのリフレクション API を介した呼び出しが動的クラス生成を使用して最適化されるかどうかを示す値を取得または設定します。デフォルト値は true です。

```csharp
public static bool UseReflectionOptimization { get; set; }
```

### 備考

この最適化を無効にした方が望ましいシナリオがいくつかあります。例えば、常に小規模なデータ項目コレクションを扱っている場合、動的クラス生成のオーバーヘッドが直接的なリフレクション API 呼び出しのオーバーヘッドよりも目立つことがあります。

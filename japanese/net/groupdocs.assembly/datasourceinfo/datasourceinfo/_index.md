### 備考

* [`XmlDataSource`](../../../groupdocs.assembly.data/xmldatasource)
* [`JsonDataSource`](../../../groupdocs.assembly.data/jsondatasource)
* [`CsvDataSource`](../../../groupdocs.assembly.data/csvdatasource)

* DataSet

* DataView
* DataRowView
* Any other arbitrary non-dynamic and non-anonymous .NET type

テンプレート ドキュメントでさまざまなタイプのデータ ソースを扱う方法については、テンプレート構文リファレンスをご覧ください（https://docs.groupdocs.com/display/assemblynet/Template+Syntax+-+Part+1+of+2#TemplateSyntax-Part1of2-UsingDataSources）。

データ ソース オブジェクトの名前が指定されている場合、テンプレート ドキュメント内でその名前を使用してデータ ソース オブジェクトとそのメンバーにアクセスできます。

データ ソース オブジェクトの名前が null または空の場合でも、コンテキスト オブジェクト メンバー アクセスを使用してテンプレート ドキュメント内のデータ ソース オブジェクトのメンバーにアクセスできます（詳細は Template Syntax Reference を参照）。ただし、データ ソース オブジェクト自体にはアクセスできません。

複数の [`DataSourceInfo`](../../datasourceinfo) インスタンスを [`DocumentAssembler`](../../documentassembler) に渡す場合、最初のデータ ソース オブジェクトの名前だけが null または空にできます。残りの名前は指定され、かつ一意である必要があります。

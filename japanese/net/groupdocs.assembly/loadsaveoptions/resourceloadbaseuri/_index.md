## LoadSaveOptions.ResourceLoadBaseUri property

HTML テンプレートドキュメントを読み込み、非 HTML 形式で保存する際に、外部リソースファイルの相対 URI を絶対 URI に解決するためのベース URI を取得または設定します。デフォルト値は空文字列です。

```csharp
public string ResourceLoadBaseUri { get; set; }
```

### 備考

ファイルから HTML ドキュメントを読み込む場合、デフォルトでそのフォルダーがベース URI として使用されますが、ストリームから HTML ドキュメントを読み込む場合は使用できません。このプロパティを設定して、ストリームから HTML ドキュメントを読み込む際のベース URI を指定するか、ファイルから読み込む際のデフォルトベース URI を上書きします。

このプロパティの値は以下の場合に無視されます：

* An HTML document being loaded contains a BASE HTML element providing a base URI.
* An HTML document being loaded is to be assembled and saved to HTML (external resource files are not loaded and relative URIs are not changed then).

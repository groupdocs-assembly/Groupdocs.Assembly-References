## LoadSaveOptions.SaveFormat property

組み立てたドキュメントを保存するファイル形式を取得または設定します。未指定がデフォルトです。

```csharp
public FileFormat SaveFormat { get; set; }
```

### 備考

このプロパティの値が指定されていない場合、[`DocumentAssembler`](../../documentassembler) は次のように動作します：

- When you specify a file path to save an assembled document, the save file format is determined upon file extension from the path.

- When you specify a stream to save an assembled document, the save file format remains the same as the file format of a loaded template document.

GroupDocs.Assembly を使用して組み立てドキュメントを任意のファイル形式に保存できるとは限らないことに注意してください。たとえば、Word 処理ファイル形式（DOCX など）から読み込んだドキュメントをスプレッドシート形式（XLSX など）に保存することはできません。GroupDocs.Assembly がサポートするロードおよびセーブのファイル形式の組み合わせについての詳細は、GroupDocs.Assembly のオンラインドキュメントをご確認ください。

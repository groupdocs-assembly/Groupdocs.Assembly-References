## LoadSaveOptions.ResourceSaveFolder property

非 HTML 形式から読み込まれた組み立てドキュメントを HTML に保存する際に、外部リソースファイルを格納するフォルダーへのパスを取得または設定します。デフォルト値は空文字列です。

```csharp
public string ResourceSaveFolder { get; set; }
```

### 備考

既定では、組み立てドキュメントをHTMLファイルに保存する際、外部リソースファイルは拡張子を除いたHTMLファイル名に\"_files\"サフィックスを付加したフォルダーに保存されます。このフォルダーはHTMLファイルと同じディレクトリに作成されます。ただし、組み立てドキュメントをHTMLストリームに保存する場合はこの方法は使用できません。このプロパティを設定して、HTMLストリームに保存する際の外部リソースファイル保存フォルダーのパスを指定するか、HTMLファイルに保存する際の既定フォルダーを上書きしてください。

このプロパティの値は、HTMLに保存される組み立てドキュメントがHTMLから読み込まれた場合は無視されます（外部リソースファイルは保存されず、リンクも変更されません）。

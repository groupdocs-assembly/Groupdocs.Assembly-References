## BarcodeSettings.BaseYDimension property

2D バーコードモジュールの単位の最小高さであるベース y 次元を取得または設定します。単位は[`GraphicsUnit`](../graphicsunit)で測定されます。

```csharp
public float BaseYDimension { get; set; }
```

### 備考

一部のタイプのバーコード（例：データマトリックス）は y 次元を無視し、幅と高さの単位の両方に x 次元を使用することがあります。

テンプレートを通じてバーコードのスケーリングが適用されると、ベース y 次元とスケーリング係数に基づいて実際の y 次元が計算されます。

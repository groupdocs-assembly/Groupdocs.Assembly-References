## BarcodeSettings.BaseXDimension property

バーコードのバーとスペースの単位の最小幅であるベース x 次元を取得または設定します。単位は[`GraphicsUnit`](../graphicsunit)で測定されます。

public float BaseXDimension { get; set; }

### 備考

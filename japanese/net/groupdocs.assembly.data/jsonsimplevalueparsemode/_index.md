## JsonSimpleValueParseMode enumeration

JSON をロードする際に、JSON の単純値（null、ブール値、数値、整数、文字列）を解析するモードを指定します。このモードは日付時刻値の解析には影響しません。

```csharp
public enum JsonSimpleValueParseMode
```

### Values

| 名前 | Value | 説明 |
| --- | --- | --- |
| Loose | `0` | JSON シンプル値の型が文字列表現の解析時に決定されるモードを指定します。例えば、JSON スニペット '{ prop: "123" }' の 'prop' の型は、このモードでは integer と判断されます。 |
| Strict | `1` | JSON シンプル値の型が JSON 表記自体から決定されるモードを指定します。例えば、JSON スニペット '{ prop: "123" }' の 'prop' の型は、このモードでは string と判断されます。 |

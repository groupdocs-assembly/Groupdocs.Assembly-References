## XmlDataLoadOptions.AlwaysGenerateRootObject property

生成されたデータソースが常に XML ルート要素用のオブジェクトを含むかどうかを示すフラグを取得または設定します。XML ルート要素に属性がなく、すべての子要素が同じ名前の場合、デフォルトではそのようなオブジェクトは作成されません。

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### 備考

既定値は **false** です。

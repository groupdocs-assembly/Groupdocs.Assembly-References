## JsonDataLoadOptions.AlwaysGenerateRootObject property

生成されたデータソースが常に JSON ルート要素用のオブジェクトを含むかどうかを示すフラグを取得または設定します。JSON ルート要素に単一の複合プロパティが含まれる場合、デフォルトではそのようなオブジェクトは作成されません。

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### 備考

既定値は **false** です。

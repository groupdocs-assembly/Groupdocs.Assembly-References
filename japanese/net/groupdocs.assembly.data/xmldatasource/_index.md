### 備考

ドキュメントを組み立てる際に対応するファイルまたはストリームのデータにアクセスするには、このクラスのインスタンスをデータ ソースとして [`DocumentAssembler`](../../groupdocs.assembly/documentassembler).AssembleDocument のオーバーロードのいずれかに渡します。

テンプレート ドキュメントでは、トップレベルの XML 要素が同じタイプの要素のリストのみを含む場合、[`XmlDataSource`](../xmldatasource) インスタンスは DataTable インスタンスと同様に扱うべきです。そうでない場合、[`XmlDataSource`](../xmldatasource) インスタンスは DataRow インスタンスと同様に扱うべきです。詳細については、テンプレート構文リファレンス (https://docs.groupdocs.com/display/assemblynet/Template+Syntax+-+Part+1+of+2#TemplateSyntax-Part1of2-UsingDataSources) を参照してください。

XML スキーマ定義がこのクラスのコンストラクタに渡されると、単純な XML 要素および属性の値のデータ型はスキーマに従って決定されます。そのため、テンプレート ドキュメントでは、文字列だけでなく型付きの値を扱うことができます。

XML スキーマ定義がこのクラスのコンストラクタに渡されない場合、単純な XML 要素および属性の値のデータ型は文字列表現に基づいて自動的に決定されます。そのため、テンプレート ドキュメントでもこの場合、型付きの値を扱うことができます。エンジンは以下の型の値を自動的に認識することが可能です：

* `long?`
* `double?`
* `bool?`
* `DateTime?`
* `string`

データ型の自動認識が機能するためには、単純な XML 要素および属性の値の文字列表現は不変カルチャ設定を使用して作成される必要があることに注意してください。

XML データ ローディングのデフォルト動作を上書きするには、[`XmlDataLoadOptions`](../xmldataloadoptions) インスタンスを初期化してこのクラスのコンストラクタに渡します。

## DocumentTableOptions.FirstRowContainsColumnNames property

ドキュメント テーブルの最初に抽出された行から列名を取得するかどうかを示す値を取得または設定します。デフォルト値は false です。

```csharp
public bool FirstRowContainsColumnNames { get; set; }
```

### 備考

ドキュメントテーブルの最初に抽出された行から列名を取得するように設定されていない場合、代わりにデフォルトの列名が使用されます。スプレッドシート形式のドキュメントでは、デフォルトの列名は A、B、C、... Z、AA、AB などと定義されます。他のファイル形式のドキュメントでは、デフォルトの列名は Column1、Column2、Column3 などと定義されます。

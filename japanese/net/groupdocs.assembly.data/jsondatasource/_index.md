### 備考

ドキュメントを組み立てる際に対応するファイルまたはストリームのデータにアクセスするには、このクラスのインスタンスをデータ ソースとして [`DocumentAssembler`](../../groupdocs.assembly/documentassembler).AssembleDocument のオーバーロードのいずれかに渡します。

テンプレート ドキュメントでは、トップレベルの JSON 要素が配列の場合、[`JsonDataSource`](../jsondatasource) インスタンスは DataTable インスタンスと同様に扱う必要があります。トップレベルの JSON 要素がオブジェクトの場合、[`JsonDataSource`](../jsondatasource) インスタンスは DataRow インスタンスと同様に扱う必要があります。詳細については、テンプレート構文リファレンス (https://docs.groupdocs.com/display/assemblynet/Template+Syntax+-+Part+1+of+2#TemplateSyntax-Part1of2-UsingDataSources) を参照してください。

テンプレート ドキュメントでは、JSON 要素の型付き値を扱うことができます。便利なように、エンジンは JSON のシンプル型の集合を以下のものに置き換えます：

* `long?`
* `double?`
* `bool?`
* `DateTime?`
* `string`

エンジンは JSON 表現に基づいて、追加型の値を自動的に認識します。

JSON データの読み込みにおけるデフォルト動作を上書きするには、[`JsonDataLoadOptions`](../jsondataloadoptions) インスタンスを初期化し、このクラスのコンストラクタに渡します。

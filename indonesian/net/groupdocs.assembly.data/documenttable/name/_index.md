## DocumentTable.Name property

Mendapatkan atau mengatur nama tabel ini yang digunakan untuk mengakses data tabel dalam dokumen templat yang diteruskan ke [`DocumentAssembler`](../../../groupdocs.assembly/documentassembler).

```csharp
public string Name { get; set; }
```

### Catatan

Jika nama tabel dibaca dari dokumen, nama tersebut secara otomatis diperbaiki agar menjadi valid. Namun, jika nama tabel diatur secara manual melalui properti ini dan nama tersebut tidak valid, sebuah pengecualian akan dilempar.

Nama tabel dianggap valid, jika kondisi berikut terpenuhi:

* The name is not empty.
* The name's first character is a letter or underscore.
* The rest of the name's characters are letters, underscores, digits, or the following characters: '@', '#', '$'.
* The corresponding [`DocumentTableSet`](../../documenttableset) object does not contain a [`DocumentTable`](../../documenttable) instance with the same name.

### Catatan

Untuk dokumen dengan format file Spreadsheet, sebuah instance [`DocumentTable`](../documenttable) mewakili satu lembar. Untuk dokumen dengan format file lain, sebuah instance [`DocumentTable`](../documenttable) mewakili satu tabel.

Untuk mengakses data tabel yang bersangkutan saat menyusun dokumen, berikan sebuah instance kelas ini sebagai sumber data ke salah satu overload [`DocumentAssembler`](../../groupdocs.assembly/documentassembler).AssembleDocument.

Dalam dokumen templat, sebuah instance [`DocumentTable`](../documenttable) harus diperlakukan sama seperti sebuah instance DataTable. Lihat referensi sintaks templat untuk informasi lebih lanjut.

## DocumentTableSet class

Menyediakan akses ke data beberapa tabel (atau spreadsheet) yang terletak dalam dokumen eksternal untuk digunakan saat menyusun dokumen. Juga, memungkinkan mendefinisikan hubungan induk-anak untuk tabel dokumen sehingga mempermudah akses ke data terkait dalam dokumen templat.

### Catatan

Untuk dokumen berformat Spreadsheet, sebuah instance [`DocumentTableSet`](../documenttableset) mewakili sekumpulan lembar. Untuk dokumen dengan format file lain, sebuah instance [`DocumentTableSet`](../documenttableset) mewakili sekumpulan tabel.

Untuk mengakses data tabel yang bersesuaian saat merakit dokumen, berikan sebuah instance kelas ini sebagai sumber data ke salah satu overload [`DocumentAssembler`](../../groupdocs.assembly/documentassembler).AssembleDocument.

Dalam dokumen templat, sebuah instance [`DocumentTableSet`](../documenttableset) harus diperlakukan dengan cara yang sama seolah-olah itu adalah instance DataSet. Lihat referensi sintaks templat untuk informasi lebih lanjut.

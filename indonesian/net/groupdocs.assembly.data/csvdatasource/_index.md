### Catatan

Untuk mengakses data file atau aliran yang bersesuaian saat menyusun dokumen, berikan sebuah instance kelas ini sebagai sumber data ke salah satu overload [`DocumentAssembler`](../../groupdocs.assembly/documentassembler).AssembleDocument.

Dalam dokumen templat, sebuah instance [`CsvDataSource`](../csvdatasource) harus diperlakukan dengan cara yang sama seolah-olah itu adalah instance DataTable. Untuk informasi lebih lanjut, lihat referensi sintaks templat (https://docs.groupdocs.com/display/assemblynet/Template+Syntax+-+Part+1+of+2#TemplateSyntax-Part1of2-UsingDataSources).

Tipe data nilai yang dipisahkan koma ditentukan secara otomatis berdasarkan representasi string mereka. Jadi dalam dokumen templat, Anda dapat bekerja dengan nilai bertipe alih-alih hanya string. Mesin ini mampu secara otomatis mengenali nilai dari tipe berikut:

* `long?`
* `double?`
* `bool?`
* `DateTime?`
* `string`

Catat bahwa agar pengenalan otomatis tipe data berfungsi, representasi string nilai yang dipisahkan koma harus dibentuk menggunakan pengaturan budaya invarian.

Untuk mengganti perilaku default pemuatan data CSV, inisialisasi dan berikan sebuah instance [`CsvDataLoadOptions`](../csvdataloadoptions) ke konstruktor kelas ini.

### Catatan

Untuk mengakses data file atau aliran yang bersesuaian saat menyusun dokumen, berikan sebuah instance kelas ini sebagai sumber data ke salah satu overload [`DocumentAssembler`](../../groupdocs.assembly/documentassembler).AssembleDocument.

Dalam dokumen templat, jika elemen XML tingkat atas hanya berisi daftar elemen dengan tipe yang sama, sebuah instance [`XmlDataSource`](../xmldatasource) harus diperlakukan sama seperti sebuah instance DataTable. Jika tidak, sebuah instance [`XmlDataSource`](../xmldatasource) harus diperlakukan sama seperti sebuah instance DataRow. Untuk informasi lebih lanjut, lihat referensi sintaks templat (https://docs.groupdocs.com/display/assemblynet/Template+Syntax+-+Part+1+of+2#TemplateSyntax-Part1of2-UsingDataSources).

Ketika Definisi Skema XML diberikan ke konstruktor kelas ini, tipe data nilai elemen XML sederhana dan atribut ditentukan sesuai skema. Jadi dalam dokumen templat, Anda dapat bekerja dengan nilai bertipe alih-alih hanya string.

Ketika Definisi Skema XML tidak diberikan ke konstruktor kelas ini, tipe data nilai elemen XML sederhana dan atribut ditentukan secara otomatis berdasarkan representasi stringnya. Jadi dalam dokumen templat, Anda juga dapat bekerja dengan nilai bertipe dalam kasus ini. Mesin dapat secara otomatis mengenali nilai dari tipe berikut:

* `long?`
* `double?`
* `bool?`
* `DateTime?`
* `string`

Perhatikan bahwa agar pengenalan otomatis tipe data berfungsi, representasi string nilai elemen XML sederhana dan atribut harus dibentuk menggunakan pengaturan budaya invarian.

Untuk mengganti perilaku default pemuatan data XML, inisialisasi dan berikan sebuah instance [`XmlDataLoadOptions`](../xmldataloadoptions) ke konstruktor kelas ini.

### Catatan

Untuk mengakses data file atau aliran yang bersesuaian saat menyusun dokumen, berikan sebuah instance kelas ini sebagai sumber data ke salah satu overload [`DocumentAssembler`](../../groupdocs.assembly/documentassembler).AssembleDocument.

Dalam dokumen templat, jika elemen JSON tingkat atas berupa array, sebuah instance [`JsonDataSource`](../jsondatasource) harus diperlakukan sama seperti instance DataTable. Jika elemen JSON tingkat atas berupa objek, sebuah instance [`JsonDataSource`](../jsondatasource) harus diperlakukan sama seperti instance DataRow. Untuk informasi lebih lanjut, lihat referensi sintaks templat (https://docs.groupdocs.com/display/assemblynet/Template+Syntax+-+Part+1+of+2#TemplateSyntax-Part1of2-UsingDataSources).

Dalam dokumen templat, Anda dapat bekerja dengan nilai bertipe dari elemen JSON. Untuk kenyamanan, mesin menggantikan kumpulan tipe sederhana JSON dengan yang berikut:

* `long?`
* `double?`
* `bool?`
* `DateTime?`
* `string`

Mesin secara otomatis mengenali nilai tipe tambahan berdasarkan representasi JSON mereka.

Untuk mengganti perilaku default pemuatan data JSON, inisialisasi dan berikan sebuah instance [`JsonDataLoadOptions`](../jsondataloadoptions) ke konstruktor kelas ini.

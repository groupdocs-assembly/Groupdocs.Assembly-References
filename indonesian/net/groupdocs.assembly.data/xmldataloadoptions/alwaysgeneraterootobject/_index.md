## XmlDataLoadOptions.AlwaysGenerateRootObject property

Mendapatkan atau mengatur flag yang menunjukkan apakah sumber data yang dihasilkan akan selalu berisi objek untuk elemen root XML. Jika elemen root XML tidak memiliki atribut dan semua elemen anaknya memiliki nama yang sama, objek semacam itu tidak dibuat secara default.

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### Catatan

Nilai default adalah **false**.

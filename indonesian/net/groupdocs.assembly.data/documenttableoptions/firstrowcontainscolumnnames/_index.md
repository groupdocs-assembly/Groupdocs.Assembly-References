## DocumentTableOptions.FirstRowContainsColumnNames property

Mendapatkan atau mengatur nilai yang menunjukkan apakah nama kolom akan diambil dari baris pertama yang diekstrak dari tabel dokumen. Nilai default adalah false.

```csharp
public bool FirstRowContainsColumnNames { get; set; }
```

### Catatan

Jika nama kolom tidak diatur untuk diambil dari baris pertama yang diekstrak dari tabel dokumen, nama kolom default akan digunakan sebagai gantinya. Untuk dokumen berformat Spreadsheet, nama kolom default didefinisikan sebagai A, B, C, ... Z, AA, AB, dan seterusnya. Untuk dokumen dengan format file lain, nama kolom default didefinisikan sebagai Column1, Column2, Column3, dan seterusnya.

## JsonSimpleValueParseMode enumeration

Menentukan mode untuk mengurai nilai sederhana JSON (null, boolean, angka, integer, dan string) saat memuat JSON. Mode tersebut tidak memengaruhi penguraian nilai tanggal-waktu.

```csharp
public enum JsonSimpleValueParseMode
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Loose | `0` | Menentukan mode di mana tipe nilai sederhana JSON ditentukan saat mengurai representasi string mereka. Misalnya, tipe 'prop' dari potongan JSON '{ prop: \"123\" }' ditentukan sebagai integer dalam mode ini. |
| Strict | `1` | Menentukan mode di mana tipe nilai sederhana JSON ditentukan dari notasi JSON itu sendiri. Misalnya, tipe 'prop' dari potongan JSON '{ prop: \"123\" }' ditentukan sebagai string dalam mode ini. |

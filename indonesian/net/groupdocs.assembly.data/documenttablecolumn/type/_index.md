## DocumentTableColumn.Type property

Mendapatkan atau mengatur tipe nilai sel dalam kolom ini.

```csharp
public Type Type { get; set; }
```

### Catatan

Untuk dokumen dengan format file non-Spreadsheet, tipe awal selalu secara otomatis ditentukan sebagai string. Untuk dokumen dengan format file Spreadsheet, tipe awal secara otomatis ditentukan tergantung pada nilai sel yang bersangkutan.

Jika sel pada kolom Spreadsheet tertentu berisi nilai dengan tipe berbeda, maka tipe awal kolom tersebut juga secara otomatis ditentukan sebagai string.

## DocumentTableColumn.Name property

Mendapatkan atau mengatur nama kolom ini yang digunakan untuk mengakses data kolom dalam dokumen templat yang diteruskan ke [`DocumentAssembler`](../../../groupdocs.assembly/documentassembler).

```csharp
public string Name { get; set; }
```

### Catatan

Jika nama kolom dibaca dari dokumen (lihat [`FirstRowContainsColumnNames`](../../documenttableoptions/firstrowcontainscolumnnames)), nama tersebut secara otomatis diperbaiki agar menjadi valid. Namun, jika nama kolom diatur secara manual melalui properti ini dan nama tersebut tidak valid, sebuah pengecualian akan dilempar.

Nama kolom dianggap valid, jika kondisi berikut terpenuhi:

* The name is not empty.
* The name's first character is a letter or underscore.
* The rest of the name's characters are letters, underscores, digits, or the following characters: '@', '#', '$'.
* The corresponding [`DocumentTable`](../../documenttable) object does not contain a [`DocumentTableColumn`](../../documenttablecolumn) instance with the same name.

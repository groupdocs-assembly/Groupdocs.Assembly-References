## JsonDataLoadOptions.AlwaysGenerateRootObject property

Mendapatkan atau mengatur flag yang menunjukkan apakah sumber data yang dihasilkan akan selalu berisi objek untuk elemen root JSON. Jika elemen root JSON berisi satu properti kompleks, objek semacam itu tidak dibuat secara default.

public bool AlwaysGenerateRootObject { get; set; }

### Catatan

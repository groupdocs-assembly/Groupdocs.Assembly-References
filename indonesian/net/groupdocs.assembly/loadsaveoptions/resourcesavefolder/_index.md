## LoadSaveOptions.ResourceSaveFolder property

Mendapatkan atau mengatur jalur ke folder untuk menyimpan file sumber daya eksternal saat dokumen yang dirakit yang dimuat dari format non-HTML sedang disimpan ke HTML. Nilai default adalah string kosong.

```csharp
public string ResourceSaveFolder { get; set; }
```

### Catatan

Secara default, saat menyimpan dokumen yang dirakit ke file HTML, file sumber daya eksternal disimpan ke folder yang memiliki nama sama dengan file HTML tanpa ekstensi ditambah akhiran "_files". Folder ini terletak di folder yang sama dengan file HTML. Namun, hal ini tidak dapat dilakukan saat menyimpan dokumen yang dirakit ke aliran HTML. Atur properti ini untuk menentukan jalur ke folder untuk menyimpan file sumber daya eksternal saat menyimpan dokumen yang dirakit ke aliran HTML atau untuk mengganti folder default saat menyimpan dokumen yang dirakit ke file HTML.

Nilai properti ini diabaikan jika dokumen yang dirakit yang disimpan ke HTML juga dimuat dari HTML (file sumber daya eksternal tidak disimpan dan tautan ke mereka tidak diubah).

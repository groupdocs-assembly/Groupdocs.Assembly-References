## DocumentAssembler.UseReflectionOptimization property

Mendapatkan atau mengatur nilai yang menunjukkan apakah pemanggilan anggota tipe khusus yang dilakukan melalui API refleksi dioptimalkan menggunakan pembuatan kelas dinamis atau tidak. Nilai default adalah true.

```csharp
public static bool UseReflectionOptimization { get; set; }
```

### Catatan

Ada beberapa skenario di mana lebih disarankan untuk menonaktifkan optimisasi ini. Misalnya, jika Anda selalu menangani koleksi data kecil, maka overhead pembuatan kelas dinamis dapat lebih terasa dibandingkan overhead pemanggilan API refleksi langsung.

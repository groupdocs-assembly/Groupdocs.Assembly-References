## BarcodeSettings.UseAutoCorrection property

Mendapatkan atau mengatur nilai yang menunjukkan apakah nilai barcode yang tidak valid harus diperbaiki secara otomatis (jika memungkinkan) agar sesuai dengan spesifikasi barcode atau apakah pengecualian harus dilemparkan untuk menunjukkan kesalahan. Nilai default adalah true.

```csharp
public bool UseAutoCorrection { get; set; }
```

### Catatan

Koreksi otomatis tidak memungkinkan untuk barcode Databar.

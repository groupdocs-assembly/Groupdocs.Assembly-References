## BarcodeSettings.BaseYDimension property

Mendapatkan atau menetapkan y-dimensi dasar, yaitu tinggi terkecil dari unit modul barcode 2D. Diukur dalam [`GraphicsUnit`](../graphicsunit).

```csharp
public float BaseYDimension { get; set; }
```

### Catatan

Barcode beberapa tipe (seperti data matrix) dapat mengabaikan y-dimensi dan menggunakan x-dimensi untuk unit lebar dan tinggi.

Ketika skala barcode diterapkan melalui templat, y-dimensi aktual dihitung berdasarkan y-dimensi dasar dan faktor skala.

## DataSourceInfo.Name property

Mendapatkan atau mengatur nama objek sumber data yang akan digunakan untuk mengakses objek sumber data dalam dokumen templat.

```csharp
public string Name { get; set; }
```

### Catatan

Ketika nama objek sumber data ditentukan, Anda dapat mengakses objek sumber data dan anggotanya dalam dokumen templat menggunakan nama tersebut.

Ketika nama objek sumber data bernilai null atau kosong, Anda masih dapat mengakses anggota objek sumber data dalam dokumen templat menggunakan akses anggota objek konteks (lihat Referensi Sintaks Templat untuk informasi lebih lanjut), tetapi Anda tidak dapat mengakses objek sumber data itu sendiri.

Saat melewatkan beberapa instance [`DataSourceInfo`](../../datasourceinfo) ke [`DocumentAssembler`](../../documentassembler), hanya nama objek sumber data pertama yang dapat bernilai null atau kosong. Nama-nama sisanya harus ditentukan dan unik.

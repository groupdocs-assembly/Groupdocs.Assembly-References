## DocumentAssemblyOptions enumeration

Menentukan opsi yang mengontrol perilaku [`DocumentAssembler`](../documentassembler) saat menyusun dokumen.

```csharp
[Flags]
public enum DocumentAssemblyOptions
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| None | `0` | Menentukan opsi default. |
| AllowMissingMembers | `1` | Menentukan bahwa anggota objek yang hilang harus diperlakukan sebagai literal null oleh assembler. Opsi ini hanya memengaruhi akses ke anggota objek instance (yaitu, non-statis) dan metode ekstensi. Jika opsi ini tidak diatur, assembler akan melemparkan pengecualian ketika menemukan anggota objek yang hilang. |
| UpdateFieldsAndFormulas | `2` | Menentukan bahwa bidang dokumen Word Processing hasil dan rumus dokumen Spreadsheet hasil harus diperbarui oleh assembler. |
| RemoveEmptyParagraphs | `4` | Menentukan bahwa assembler harus menghapus paragraf yang menjadi kosong setelah tag sintaks templat dihapus atau diganti dengan nilai kosong. |
| InlineErrorMessages | `8` | Menentukan bahwa assembler harus menyisipkan pesan kesalahan sintaks templat ke dalam dokumen output. Jika opsi ini tidak diatur, assembler akan melemparkan pengecualian ketika menemukan kesalahan sintaks. |
| UseSpreadsheetDataTypes | `10` | Hanya terkait dengan dokumen Spreadsheet. Menentukan bahwa hasil ekspresi yang dievaluasi harus dipetakan ke tipe data Spreadsheet yang sesuai, yang juga memengaruhi pemformatan default mereka dalam sel. Jika opsi ini tidak diatur, hasil ekspresi selalu ditulis sebagai string oleh assembler. Opsi ini tidak berpengaruh ketika hasil ekspresi diformat menggunakan sintaks templat - hasil ekspresi tetap selalu ditulis sebagai string. |

## XmlDataLoadOptions.AlwaysGenerateRootObject property

생성된 데이터 소스가 XML 루트 요소에 대해 항상 객체를 포함할지 여부를 나타내는 플래그를 가져오거나 설정합니다. XML 루트 요소에 속성이 없고 모든 자식 요소가 동일한 이름을 가질 경우 기본적으로 해당 객체는 생성되지 않습니다.

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### 비고

기본값은 **false**입니다.

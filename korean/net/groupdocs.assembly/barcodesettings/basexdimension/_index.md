## BarcodeSettings.BaseXDimension property

```csharp
public float BaseXDimension { get; set; }
```

### 비고

템플릿을 통해 바코드 스케일링이 적용되면, 실제 x-차원은 기본 x-차원과 스케일링 계수를 기반으로 계산됩니다.

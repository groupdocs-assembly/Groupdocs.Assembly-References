## BarcodeSettings.UseAutoCorrection property

잘못된 바코드 값이 바코드 사양에 맞게 자동으로(가능한 경우) 수정되어야 하는지, 아니면 오류를 나타내기 위해 예외가 발생해야 하는지를 나타내는 값을 가져오거나 설정합니다. 기본값은 true입니다.

```csharp
public bool UseAutoCorrection { get; set; }
```

### 비고

Databar 바코드에 대해서는 자동 수정이 불가능합니다.

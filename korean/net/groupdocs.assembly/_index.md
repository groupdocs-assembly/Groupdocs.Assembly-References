템플릿 문서와 데이터베이스, XML, JSON, OData, 사용자 정의 .NET 형식의 객체 등 다양한 소스에서 얻은 데이터를 기반으로 인기 있는 오피스 파일 형식의 문서를 생성하는 클래스를 제공합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [BarcodeSettings](./barcodesettings) | 문서를 조립하는 동안 바코드 생성을 제어하는 설정 집합을 나타냅니다. |
| [DataSourceInfo](./datasourceinfo) | 템플릿에서 문서를 조립하는 데 사용되는 단일 데이터 소스 객체에 대한 정보를 제공합니다. |
| [DocumentAssembler](./documentassembler) | 데이터와 이러한 루틴을 제어하는 설정 집합으로 템플릿 문서를 채우는 루틴을 제공합니다. |
| [KnownTypeSet](./knowntypeset) | 문서 템플릿 내에서 해당 타입의 정적 멤버를 호출하거나 형 변환 등을 수행하기 위해 완전하거나 부분적으로 한정된 이름을 사용할 수 있는 Type 객체를 포함하는 순서가 없는 집합(즉, 고유 항목의 컬렉션)을 나타냅니다. |
| [License](./license) | 구성 요소에 라이선스를 적용하는 메서드를 제공합니다. |
| [LoadSaveOptions](./loadsaveoptions) | 조립될 문서를 로드하고 저장하기 위한 추가 옵션을 지정합니다. |
| [Metered](./metered) | 계량 라이선스를 다루는 메서드를 제공합니다. |
## 열거형

| 열거형 | 설명 |

| [FileFormat](./fileformat) | 파일 형식을 지정합니다. |

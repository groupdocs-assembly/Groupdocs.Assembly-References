## KnownTypeSet class

Représente un ensemble non ordonné (c'est‑à‑dire une collection d'éléments uniques) contenant des objets Type dont les noms entièrement ou partiellement qualifiés peuvent être utilisés dans les modèles de documents pour invoquer les membres statiques des types correspondants, effectuer des conversions de type, etc.

## DocumentTableColumn.Type property

Obtient ou définit le type des valeurs de cellule dans cette colonne.

```csharp
public Type Type { get; set; }
```

### Remarques

Pour les documents de formats de fichier non‑Spreadsheet, le type initial est toujours déterminé automatiquement comme chaîne. Pour les documents de formats de fichier Spreadsheet, le type initial est déterminé automatiquement en fonction des valeurs des cellules correspondantes.

Si les cellules d'une colonne Spreadsheet particulière contiennent des valeurs de types différents, le type initial de la colonne est également déterminé automatiquement comme chaîne.

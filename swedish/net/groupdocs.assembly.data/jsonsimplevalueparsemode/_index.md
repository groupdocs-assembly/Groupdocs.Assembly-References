## JsonSimpleValueParseMode enumeration

Anger ett läge för att tolka enkla JSON‑värden (null, boolean, number, integer och string) vid inläsning av JSON. Ett sådant läge påverkar inte tolkning av datum‑tid‑värden.

```csharp
public enum JsonSimpleValueParseMode
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Loose | `0` | Anger läget där typerna för enkla JSON‑värden bestäms vid tolkning av deras strängrepresentationer. Till exempel bestäms typen för 'prop' från JSON‑snutten '{ prop: \"123\" }' som integer i detta läge. |
| Strict | `1` | Anger läget där typerna för enkla JSON‑värden bestäms utifrån JSON‑notationen själv. Till exempel bestäms typen för 'prop' från JSON‑snutten '{ prop: \"123\" }' som string i detta läge. |

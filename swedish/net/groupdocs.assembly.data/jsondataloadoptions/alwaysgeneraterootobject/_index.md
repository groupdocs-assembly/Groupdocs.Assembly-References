## JsonDataLoadOptions.AlwaysGenerateRootObject property

Hämtar eller anger en flagga som indikerar om en genererad datakälla alltid kommer att innehålla ett objekt för ett JSON‑rootelement. Om ett JSON‑rootelement innehåller en enda komplex egenskap skapas ett sådant objekt inte som standard.

public bool AlwaysGenerateRootObject { get; set; }

### Anmärkningar

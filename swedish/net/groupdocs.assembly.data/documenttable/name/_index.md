## DocumentTable.Name property

Hämtar eller anger namnet på denna tabell som används för att komma åt tabellens data i ett mall‑dokument som skickas till [`DocumentAssembler`](../../../groupdocs.assembly/documentassembler).

```csharp
public string Name { get; set; }
```

### Anmärkningar

Om tabellens namn läses från ett dokument korrigeras namnet automatiskt så att det blir giltigt. Om tabellens namn däremot sätts manuellt via denna egenskap och namnet är ogiltigt, kastas ett undantag.

Tabellens namn anses vara giltigt om följande villkor uppfylls:

* The name is not empty.
* The name's first character is a letter or underscore.
* The rest of the name's characters are letters, underscores, digits, or the following characters: '@', '#', '$'.
* The corresponding [`DocumentTableSet`](../../documenttableset) object does not contain a [`DocumentTable`](../../documenttable) instance with the same name.

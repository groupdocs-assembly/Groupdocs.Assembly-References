## XmlDataLoadOptions.AlwaysGenerateRootObject property

Hämtar eller anger en flagga som indikerar om en genererad datakälla alltid ska innehålla ett objekt för ett XML‑rootelement. Om ett XML‑rootelement saknar attribut och alla dess underordnade element har samma namn, skapas ett sådant objekt inte som standard.

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### Anmärkningar

Standardvärdet är **false**.

## DocumentAssembler.UseReflectionOptimization property

Hämtar eller anger ett värde som indikerar om anrop av anpassade typmedlemmar som utförs via reflektion‑API optimeras med dynamisk klassgenerering eller inte. Standardvärdet är true.

```csharp
public static bool UseReflectionOptimization { get; set; }
```

### Anmärkningar

Det finns vissa scenarier där det är att föredra att inaktivera denna optimering. Till exempel, om du hela tiden hanterar små samlingar av dataobjekt, kan en overhead av dynamisk klassgenerering vara mer märkbar än en overhead av direkta reflektion-API-anrop.

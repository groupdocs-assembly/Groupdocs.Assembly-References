## BarcodeSettings.UseAutoCorrection property

Hämtar eller anger ett värde som indikerar om ett ogiltigt streckkodsvärde ska korrigeras automatiskt (om möjligt) för att passa streckkodens specifikation eller om ett undantag ska kastas för att indikera felet. Standardvärdet är true.

```csharp
public bool UseAutoCorrection { get; set; }
```

### Anmärkningar

Den automatiska korrigeringen är inte möjlig för Databar-streckkoder.

## LoadSaveOptions.ResourceSaveFolder property

Hämtar eller anger en sökväg till en mapp för att lagra externa resursfiler medan ett sammansatt dokument som lästs in från ett icke‑HTML‑format sparas till HTML. Standardvärdet är en tom sträng.

```csharp
public string ResourceSaveFolder { get; set; }
```

### Anmärkningar

Som standard, när ett sammansatt dokument sparas till en HTML‑fil, lagras externa resursfiler i en mapp som har samma namn som HTML‑filen utan filändelse plus suffixet "_files". Denna mapp ligger i samma katalog som HTML‑filen. Detta kan dock inte göras när ett sammansatt dokument sparas till en HTML‑ström. Ställ in denna egenskap för att ange en sökväg till en mapp för att lagra externa resursfiler när ett sammansatt dokument sparas till en HTML‑ström eller för att åsidosätta standardmappen när ett sammansatt dokument sparas till en HTML‑fil.

Ett värde för denna egenskap ignoreras om ett sammansatt dokument som sparas till HTML också laddades från HTML (externa resursfiler lagras då inte och länkar till dem ändras inte).

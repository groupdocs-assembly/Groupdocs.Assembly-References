## LoadSaveOptions.ResourceLoadBaseUri property

Hämtar eller anger en bas‑URI för att lösa externa resursfils relativa URI:er till absoluta när ett HTML‑mall‑dokument laddas för sammansättning och sparas till ett icke‑HTML‑format. Standardvärdet är en tom sträng.

```csharp
public string ResourceLoadBaseUri { get; set; }
```

### Anmärkningar

När ett HTML‑dokument laddas från en fil används dess innehållande mapp som bas‑URI som standard, vilket inte kan ske när ett HTML‑dokument laddas från en ström. Ställ in denna egenskap för att ange en bas‑URI när ett HTML‑dokument laddas från en ström eller för att åsidosätta standard‑URI:n när ett HTML‑dokument laddas från en fil.

Ett värde för denna egenskap ignoreras i följande fall:

* An HTML document being loaded contains a BASE HTML element providing a base URI.
* An HTML document being loaded is to be assembled and saved to HTML (external resource files are not loaded and relative URIs are not changed then).

## LoadSaveOptions.SaveFormat property

Hämtar eller anger ett filformat att spara ett sammansatt dokument till. Ospecificerat är standardvärdet.

```csharp
public FileFormat SaveFormat { get; set; }
```

### Anmärkningar

När värdet för denna egenskap inte är specificerat, beter sig [`DocumentAssembler`](../../documentassembler) enligt följande:

- When you specify a file path to save an assembled document, the save file format is determined upon file extension from the path.

- When you specify a stream to save an assembled document, the save file format remains the same as the file format of a loaded template document.

Observera att det inte alltid är möjligt att spara ett sammansatt dokument till något filformat med GroupDocs.Assembly. Till exempel är det omöjligt att spara ett dokument som laddats från ett ordbehandlingsfilformat (såsom DOCX) till ett kalkylbladsfilformat (såsom XLSX). För mer information om möjliga kombinationer av inläsnings- och sparfilformat som stöds av GroupDocs.Assembly, vänligen kontrollera GroupDocs.Assembly online-dokumentation.

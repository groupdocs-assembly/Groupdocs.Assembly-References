### 备注

在组装文档时访问相应文件或流的数据，请将此类的实例作为数据源传递给 [`DocumentAssembler`](../../groupdocs.assembly/documentassembler).AssembleDocument 的任一重载。

在模板文档中，如果顶层 XML 元素仅包含同类型元素的列表，则应将 [`XmlDataSource`](../xmldatasource) 实例视为 DataTable 实例。否则，应将 [`XmlDataSource`](../xmldatasource) 实例视为 DataRow 实例。欲了解更多信息，请参阅模板语法参考 (https://docs.groupdocs.com/display/assemblynet/Template+Syntax+-+Part+1+of+2#TemplateSyntax-Part1of2-UsingDataSources)。

当将 XML 架构定义传递给此类的构造函数时，简单 XML 元素和属性值的数据类型将根据模式确定。因此，在模板文档中，您可以使用类型化的值，而不仅仅是字符串。

当未将 XML 架构定义传递给此类的构造函数时，简单 XML 元素和属性值的数据类型将根据其字符串表示自动确定。因此，在模板文档中，您也可以在此情况下使用类型化的值。引擎能够自动识别以下类型的值：

* `long?`
* `double?`
* `bool?`
* `DateTime?`
* `string`

请注意，为使数据类型的自动识别生效，简单 XML 元素和属性值的字符串表示应使用不变文化设置生成。

要覆盖 XML 数据加载的默认行为，请初始化并将 [`XmlDataLoadOptions`](../xmldataloadoptions) 实例传递给此类的构造函数。

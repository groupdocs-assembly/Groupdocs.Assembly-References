## JsonSimpleValueParseMode enumeration

指定在加载 JSON 时解析 JSON 简单值（null、布尔值、数字、整数和字符串）的模式。此模式不影响日期时间值的解析。

```csharp
public enum JsonSimpleValueParseMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Loose | `0` | 指定一种模式，在该模式下 JSON 简单值的类型通过解析其字符串表示来确定。例如，在此模式中，JSON 片段 '{ prop: \"123\" }' 中 'prop' 的类型被确定为 integer。 |
| Strict | `1` | 指定一种模式，在该模式下 JSON 简单值的类型直接依据 JSON 表示法确定。例如，在此模式中，JSON 片段 '{ prop: \"123\" }' 中 'prop' 的类型被确定为 string。 |

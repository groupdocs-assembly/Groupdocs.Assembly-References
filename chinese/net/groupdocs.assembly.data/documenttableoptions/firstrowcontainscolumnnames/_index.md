## DocumentTableOptions.FirstRowContainsColumnNames property

获取或设置一个值，指示是否应从文档表的第一行提取列名。默认值为 false。

```csharp
public bool FirstRowContainsColumnNames { get; set; }
```

### 备注

如果未设置从文档表格的第一行提取列名，则使用默认列名。对于电子表格文件格式的文档，默认列名定义为 A、B、C、... Z、AA、AB 等。对于其他文件格式的文档，默认列名定义为 Column1、Column2、Column3 等。

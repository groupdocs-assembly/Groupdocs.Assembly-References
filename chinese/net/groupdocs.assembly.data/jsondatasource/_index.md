### 备注

在组装文档时访问相应文件或流的数据，请将此类的实例作为数据源传递给 [`DocumentAssembler`](../../groupdocs.assembly/documentassembler).AssembleDocument 的任一重载。

在模板文档中，如果顶层 JSON 元素是数组，则应将 [`JsonDataSource`](../jsondatasource) 实例视为 DataTable 实例；如果顶层 JSON 元素是对象，则应将 [`JsonDataSource`](../jsondatasource) 实例视为 DataRow 实例。有关更多信息，请参阅模板语法参考（https://docs.groupdocs.com/display/assemblynet/Template+Syntax+-+Part+1+of+2#TemplateSyntax-Part1of2-UsingDataSources）。

在模板文档中，您可以使用 JSON 元素的类型化值。为方便起见，引擎将 JSON 简单类型集合替换为如下类型：

* `long?`
* `double?`
* `bool?`
* `DateTime?`
* `string`

引擎会根据 JSON 表示自动识别额外类型的值。

要覆盖 JSON 数据加载的默认行为，请初始化并将 [`JsonDataLoadOptions`](../jsondataloadoptions) 实例传递给此类的构造函数。

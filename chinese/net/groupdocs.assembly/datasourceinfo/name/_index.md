## DataSourceInfo.Name property

获取或设置用于在模板文档中访问数据源对象的数据源对象名称。

```csharp
public string Name { get; set; }
```

### 备注

当指定数据源对象的名称时，您可以在模板文档中使用该名称访问数据源对象及其成员。

当数据源对象的名称为 null 或为空时，仍然可以在模板文档中使用上下文对象成员访问（有关更多信息，请参阅模板语法参考）来访问数据源对象的成员，但无法访问数据源对象本身。

当将多个[`DataSourceInfo`](../../datasourceinfo)实例传递给[`DocumentAssembler`](../../documentassembler)时，只有第一个数据源对象的名称可以为 null 或为空。其余对象的名称必须指定且唯一。

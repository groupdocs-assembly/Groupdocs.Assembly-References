## BarcodeSettings.BaseYDimension property

获取或设置基准 y 维度，即 2D 条码模块单元的最小高度。以 [`GraphicsUnit`](../graphicsunit) 为单位进行测量。

```csharp
public float BaseYDimension { get; set; }
```

### 备注

某些类型的条码（例如 Data Matrix）可能会忽略 y 维度，而使用 x 维度作为宽度和高度的单位。

当通过模板应用条码缩放时，会根据基准 y 维度和缩放因子计算实际的 y 维度。

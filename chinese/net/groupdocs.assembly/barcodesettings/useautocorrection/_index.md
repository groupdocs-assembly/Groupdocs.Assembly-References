## BarcodeSettings.UseAutoCorrection property

获取或设置一个值，指示是否应自动（如果可能）纠正无效的条形码值以符合条形码规范，或者抛出异常以指示错误。默认值为 true。

```csharp
public bool UseAutoCorrection { get; set; }
```

### 备注

Databar 条码不支持自动纠正。

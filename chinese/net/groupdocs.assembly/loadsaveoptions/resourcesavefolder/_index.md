## LoadSaveOptions.ResourceSaveFolder property

获取或设置一个文件夹路径，用于在将从非 HTML 格式加载的组装文档保存为 HTML 时存储外部资源文件。默认值为空字符串。

```csharp
public string ResourceSaveFolder { get; set; }
```

### 备注

默认情况下，将组装文档保存为HTML文件时，外部资源文件会存储在一个文件夹中，该文件夹的名称与HTML文件（不含扩展名）相同，并加上\"_files\"后缀。该文件夹位于HTML文件所在的同一目录中。然而，在将组装文档保存为HTML流时无法使用此方式。设置此属性可指定在将组装文档保存为HTML流时存储外部资源文件的文件夹路径，或在将组装文档保存为HTML文件时覆盖默认文件夹。

如果正在保存为HTML的组装文档同样是从HTML加载的，则此属性的值会被忽略（外部资源文件不会被存储，且对它们的链接也不会被更改）。

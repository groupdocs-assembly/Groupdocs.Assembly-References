## AssembleDocument(string, string, params DataSourceInfo[]) {#assembledocument_2}

从指定的源路径加载模板文档，使用指定的单个或多个源的数据填充模板文档，并使用默认的 [`LoadSaveOptions`](../../loadsaveoptions) 将结果文档存储到目标路径。

```csharp
public bool AssembleDocument(string sourcePath, string targetPath, 
    params DataSourceInfo[] dataSourceInfos)
```

| Parameter | Type | 描述 |
| --- | --- | --- |
| sourcePath | String | 用于填充数据的模板文档的路径。 |
| targetPath | String | 结果文档的路径。 |
| dataSourceInfos | DataSourceInfo[] | 提供要使用的数据源对象的信息。 |

### 返回值

一个标志，指示模板文档的解析是否成功。仅当 [`Options`](../options) 属性的值包含 InlineErrorMessages 选项时，返回的标志才有意义。

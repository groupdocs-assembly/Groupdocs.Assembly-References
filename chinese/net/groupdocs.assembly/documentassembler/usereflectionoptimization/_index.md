## DocumentAssembler.UseReflectionOptimization property

获取或设置一个值，指示是否通过反射 API 对自定义类型成员的调用使用动态类生成进行优化。默认值为 true。

```csharp
public static bool UseReflectionOptimization { get; set; }
```

### 备注

在某些情况下，禁用此优化更为合适。例如，如果您一直在处理小规模的数据项集合，那么动态类生成的开销可能比直接反射 API 调用的开销更为明显。

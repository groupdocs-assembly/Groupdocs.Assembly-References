## DocumentAssemblyOptions enumeration

指定控制 [`DocumentAssembler`](../documentassembler) 在组装文档时行为的选项。

```csharp
[Flags]
public enum DocumentAssemblyOptions
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | 指定默认选项。 |
| AllowMissingMembers | `1` | 指定缺失的对象成员应由装配器视为 null 字面量。此选项仅影响对实例（即非静态）对象成员和扩展方法的访问。如果未设置此选项，装配器在遇到缺失的对象成员时会抛出异常。 |
| UpdateFieldsAndFormulas | `2` | 指定装配器应更新结果 Word 处理文档的字段以及结果 Spreadsheet 文档的公式。 |
| RemoveEmptyParagraphs | `4` | 指定装配器在模板语法标签被移除或替换为空值后，应删除变为空的段落。 |
| InlineErrorMessages | `8` | 指定装配器应将模板语法错误信息内联到输出文档中。如果未设置此选项，装配器在遇到语法错误时会抛出异常。 |
| UseSpreadsheetDataTypes | `10` | 仅适用于 Spreadsheet 文档。指定已评估的表达式结果应映射到相应的 Spreadsheet 数据类型，这也会影响它们在单元格中的默认格式。如果未设置此选项，装配器始终将表达式结果写为字符串。当使用模板语法格式化表达式结果时，此选项无效——表达式结果仍始终写为字符串。 |

## KnownTypeSet class

Stellt eine ungeordnete Menge (d. h. eine Sammlung eindeutiger Elemente) dar, die Type‑Objekte enthält, deren vollständig oder teilweise qualifizierte Namen innerhalb von Dokumentvorlagen verwendet werden können, um die statischen Mitglieder der entsprechenden Typen aufzurufen, Typumwandlungen durchzuführen usw.

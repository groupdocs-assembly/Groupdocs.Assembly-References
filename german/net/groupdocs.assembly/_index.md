Stellt Klassen zum Erzeugen von Dokumenten in gängigen Office-Dateiformaten bereit, basierend auf Vorlagendokumenten und Daten, die aus verschiedenen Quellen wie Datenbanken, XML, JSON, OData, Objekten benutzerdefinierter .NET‑Typen und mehr gewonnen werden.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [BarcodeSettings](./barcodesettings) | Stellt einen Satz von Einstellungen dar, die die Barcode‑Erstellung beim Zusammenstellen eines Dokuments steuern. |
| [DataSourceInfo](./datasourceinfo) | Stellt Informationen zu einem einzelnen Datenquellen‑Objekt bereit, das zum Zusammenstellen eines Dokuments aus einer Vorlage verwendet wird. |
| [DocumentAssembler](./documentassembler) | Stellt Routinen zum Befüllen von Vorlagendokumenten mit Daten sowie einen Satz von Einstellungen zur Steuerung dieser Routinen bereit. |
| [KnownTypeSet](./knowntypeset) | Stellt eine ungeordnete Menge (d. h. eine Sammlung eindeutiger Elemente) dar, die Type‑Objekte enthält, deren vollständig oder teilweise qualifizierte Namen innerhalb von Dokumentvorlagen verwendet werden können, um die statischen Mitglieder der entsprechenden Typen aufzurufen, Typumwandlungen durchzuführen usw. |
| [License](./license) | Stellt Methoden zur Lizenzierung der Komponente bereit. |
| [LoadSaveOptions](./loadsaveoptions) | Gibt zusätzliche Optionen für das Laden und Speichern eines zu zusammenstellenden Dokuments an. |
| [Metered](./metered) | Stellt Methoden zur Arbeit mit nutzungsbasierten Lizenzen bereit. |

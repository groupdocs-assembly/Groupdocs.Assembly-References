## BarcodeSettings.BaseXDimension property

Liest oder legt eine Basis-X-Dimension fest, das heißt, die kleinste Breite der Einheit von Barcode-Balken und -Lücken. Gemessen in [`GraphicsUnit`](../graphicsunit).

```csharp
public float BaseXDimension { get; set; }
```

### Hinweise

Wenn die Barcode-Skalierung über eine Vorlage angewendet wird, wird eine tatsächliche X-Dimension basierend auf der Basis-X-Dimension und einem Skalierungsfaktor berechnet.

## BarcodeSettings.UseAutoCorrection property

Liest oder setzt einen Wert, der angibt, ob ein ungültiger Barcode‑Wert automatisch (wenn möglich) korrigiert werden soll, um der Spezifikation zu entsprechen, oder ob eine Ausnahme ausgelöst werden soll, um den Fehler anzuzeigen. Der Standardwert ist true.

```csharp
public bool UseAutoCorrection { get; set; }
```

### Hinweise

Die automatische Korrektur ist für Databar-Barcodes nicht möglich.

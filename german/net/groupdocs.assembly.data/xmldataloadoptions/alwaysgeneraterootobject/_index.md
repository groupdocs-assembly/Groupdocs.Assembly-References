## XmlDataLoadOptions.AlwaysGenerateRootObject property

Liest oder setzt ein Flag, das angibt, ob eine erzeugte Datenquelle stets ein Objekt für ein XML‑Stammelement enthält. Wenn ein XML‑Stammelement keine Attribute hat und alle seine Kind‑Elemente denselben Namen besitzen, wird ein solches Objekt standardmäßig nicht erstellt.

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### Hinweise

Der Standardwert ist **false**.

## DocumentTableOptions.FirstRowContainsColumnNames property

Ruft den Wert ab oder legt ihn fest, der angibt, ob Spaltennamen aus der zuerst extrahierten Zeile einer Dokumenttabelle übernommen werden sollen. Der Standardwert ist false.

```csharp
public bool FirstRowContainsColumnNames { get; set; }
```

### Hinweise

Wenn Spaltennamen nicht aus der ersten extrahierten Zeile einer Dokumenttabelle übernommen werden, werden stattdessen Standardspaltennamen verwendet. Für Dokumente im Spreadsheet-Dateiformat werden Standardspaltennamen als A, B, C, ... Z, AA, AB usw. definiert. Für Dokumente anderer Dateiformate werden Standardspaltennamen als Column1, Column2, Column3 usw. definiert.

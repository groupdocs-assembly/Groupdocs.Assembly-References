## JsonDataLoadOptions.AlwaysGenerateRootObject property

Liest oder setzt ein Flag, das angibt, ob eine erzeugte Datenquelle immer ein Objekt für ein JSON‑Stammelement enthält. Wenn ein JSON‑Stammelement eine einzelne komplexe Eigenschaft enthält, wird ein solches Objekt standardmäßig nicht erstellt.

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### Hinweise

Der Standardwert ist **false**.

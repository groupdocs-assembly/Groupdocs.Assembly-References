### Hinweise

Für Dokumente von Nicht-Spreadsheet-Dateiformaten wird der Anfangstyp immer automatisch als Zeichenkette bestimmt. Für Dokumente von Spreadsheet-Dateiformaten wird der Anfangstyp automatisch abhängig von den entsprechenden Zellwerten bestimmt.

Wenn Zellen einer bestimmten Spreadsheet-Spalte Werte unterschiedlicher Typen enthalten, wird der Anfangstyp der Spalte ebenfalls automatisch als Zeichenkette bestimmt.

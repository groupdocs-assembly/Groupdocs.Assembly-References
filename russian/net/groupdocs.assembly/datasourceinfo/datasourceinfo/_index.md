## DataSourceInfo(object, string) {#constructor_2}

Создает новый экземпляр этого класса с указанным объектом источника данных и его именем.

```csharp
public DataSourceInfo(object dataSource, string name)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| dataSource | Object | Объект источника данных. |
| name | String | Имя объекта источника данных, используемого для доступа к объекту источника данных в шаблонном документе. |

### Примечания

Объект источника данных может быть одного из следующих типов:

* [`XmlDataSource`](../../../groupdocs.assembly.data/xmldatasource)
* [`JsonDataSource`](../../../groupdocs.assembly.data/jsondatasource)
* [`CsvDataSource`](../../../groupdocs.assembly.data/csvdatasource)
* [`DocumentTableSet`](../../../groupdocs.assembly.data/documenttableset)
* [`DocumentTable`](../../../groupdocs.assembly.data/documenttable)
* DataSet
* DataTable
* DataRow
* IDataReader
* IDataRecord
* DataView
* DataRowView
* Any other arbitrary non-dynamic and non-anonymous .NET type

Для получения информации о работе с источниками данных разных типов в шаблонных документах см. справочник по синтаксису шаблонов (https://docs.groupdocs.com/display/assemblynet/Template+Syntax+-+Part+1+of+2#TemplateSyntax-Part1of2-UsingDataSources).

Когда имя объекта источника данных указано, вы можете получить доступ к объекту источника данных и его членам в шаблонном документе, используя имя.

Когда имя объекта источника данных равно null или пусто, вы всё равно можете получить доступ к членам объекта источника данных в шаблонном документе, используя доступ к членам контекстного объекта (см. справочник по синтаксису шаблонов для получения дополнительной информации), но вы не можете получить доступ к самому объекту источника данных.

При передаче нескольких экземпляров [`DataSourceInfo`](../../datasourceinfo) в [`DocumentAssembler`](../../documentassembler) только имя первого объекта источника данных может быть null или пустым. Имена остальных объектов должны быть указаны и уникальны.

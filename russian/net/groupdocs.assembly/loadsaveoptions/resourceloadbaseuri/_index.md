## LoadSaveOptions.ResourceLoadBaseUri property

Получает или задает базовый URI для преобразования относительных URI внешних файлов ресурсов в абсолютные при загрузке HTML‑шаблона, который будет собран и сохранён в не‑HTML формат. Значение по умолчанию — пустая строка.

```csharp
public string ResourceLoadBaseUri { get; set; }
```

### Примечания

При загрузке HTML‑документа из файла его содержащая папка используется в качестве базового URI по умолчанию, что невозможно при загрузке HTML‑документа из потока. Установите это свойство, чтобы указать базовый URI при загрузке HTML‑документа из потока или переопределить базовый URI по умолчанию при загрузке HTML‑документа из файла.

Значение этого свойства игнорируется в следующих случаях:

* An HTML document being loaded contains a BASE HTML element providing a base URI.
* An HTML document being loaded is to be assembled and saved to HTML (external resource files are not loaded and relative URIs are not changed then).

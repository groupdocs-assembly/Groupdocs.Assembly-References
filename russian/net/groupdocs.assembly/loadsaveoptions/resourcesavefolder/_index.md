## LoadSaveOptions.ResourceSaveFolder property

Получает или задает путь к папке для хранения внешних файлов ресурсов, когда собранный документ, загруженный из не‑HTML формата, сохраняется в HTML. Значение по умолчанию — пустая строка.

```csharp
public string ResourceSaveFolder { get; set; }
```

### Примечания

По умолчанию при сохранении собираемого документа в файл HTML внешние файлы ресурсов сохраняются в папку, имя которой совпадает с именем HTML‑файла без расширения, с суффиксом "_files". Эта папка находится в той же директории, что и HTML‑файл. Однако это невозможно при сохранении собираемого документа в поток HTML. Установите это свойство, чтобы указать путь к папке для хранения внешних файлов ресурсов при сохранении собираемого документа в поток HTML, либо чтобы переопределить папку по умолчанию при сохранении собираемого документа в файл HTML.

Значение этого свойства игнорируется, если сохраняемый в HTML собираемый документ был загружен из HTML (внешние файлы ресурсов не сохраняются, и ссылки на них не изменяются).

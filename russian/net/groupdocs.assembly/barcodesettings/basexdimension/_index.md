## BarcodeSettings.BaseXDimension property

Получает или задает базовый x‑размер, то есть наименьшую ширину единицы штрих‑кода (полосы и пробелы). Измеряется в [`GraphicsUnit`](../graphicsunit).

```csharp
public float BaseXDimension { get; set; }
```

### Примечания

Когда масштабирование штрих‑кода применяется через шаблон, фактический x‑размер рассчитывается на основе базового x‑размера и коэффициента масштабирования.

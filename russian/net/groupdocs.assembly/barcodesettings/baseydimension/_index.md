## BarcodeSettings.BaseYDimension property

Получает или задает базовый y‑размер, то есть наименьшую высоту единицы 2D‑модулей штрих‑кода. Измеряется в [`GraphicsUnit`](../graphicsunit).

```csharp
public float BaseYDimension { get; set; }
```

### Примечания

Штрих‑коды некоторых типов (например, Data Matrix) могут игнорировать y‑размер и использовать x‑размер для единиц ширины и высоты.

Когда масштабирование штрих‑кода применяется через шаблон, фактический y‑размер рассчитывается на основе базового y‑размера и коэффициента масштабирования.

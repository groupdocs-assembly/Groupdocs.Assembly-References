## BarcodeSettings.UseAutoCorrection property

Получает или задает значение, указывающее, следует ли автоматически исправлять недопустимое значение штрихкода (если возможно), чтобы соответствовать спецификации штрихкода, или выбрасывать исключение для указания ошибки. Значение по умолчанию — true.

```csharp
public bool UseAutoCorrection { get; set; }
```

### Примечания

Автокоррекция недоступна для штрих‑кодов Databar.

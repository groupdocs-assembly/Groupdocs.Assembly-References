## DocumentAssemblyOptions enumeration

Указывает параметры, контролирующие поведение [`DocumentAssembler`](../documentassembler) при сборке документа.

```csharp
[Flags]
public enum DocumentAssemblyOptions
```

### Values

| Имя | Value | Описание |
| --- | --- | --- |
| None | `0` | Указывает параметры по умолчанию. |
| AllowMissingMembers | `1` | Указывает, что отсутствующие члены объекта должны рассматриваться ассемблером как литералы null. Этот параметр влияет только на доступ к членам экземпляра (то есть нестатическим) объекта и методам расширения. Если параметр не установлен, ассемблер генерирует исключение при обнаружении отсутствующего члена объекта. |
| UpdateFieldsAndFormulas | `2` | Указывает, что поля результирующих документов обработки текста и формулы результирующих электронных таблиц должны обновляться ассемблером. |
| RemoveEmptyParagraphs | `4` | Указывает, что ассемблер должен удалять абзацы, ставшие пустыми после удаления тегов синтаксиса шаблона или их замены пустыми значениями. |
| InlineErrorMessages | `8` | Указывает, что ассемблер должен внедрять сообщения об ошибках синтаксиса шаблона непосредственно в выходные документы. Если параметр не установлен, ассемблер генерирует исключение при обнаружении синтаксической ошибки. |
| UseSpreadsheetDataTypes | `10` | Относится только к документам Spreadsheet. Указывает, что результаты вычисленных выражений должны быть сопоставлены соответствующим типам данных Spreadsheet, что также влияет на их форматирование по умолчанию в ячейках. Если параметр не установлен, ассемблер всегда записывает результаты выражений как строки. Этот параметр не действует, когда результаты выражений форматируются с помощью синтаксиса шаблона — в этом случае результаты также всегда записываются как строки. |

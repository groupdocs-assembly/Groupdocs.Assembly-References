## DocumentTable.Name property

Получает или задает имя этой таблицы, используемое для доступа к данным таблицы в шаблонном документе, переданном в [`DocumentAssembler`](../../../groupdocs.assembly/documentassembler).

```csharp
public string Name { get; set; }
```

### Примечания

Если имя таблицы читается из документа, оно автоматически корректируется, чтобы быть действительным. Однако если имя таблицы задаётся вручную через это свойство и является недействительным, генерируется исключение.

Имя таблицы считается действительным, если выполнены следующие условия:

* The name is not empty.
* The name's first character is a letter or underscore.
* The rest of the name's characters are letters, underscores, digits, or the following characters: '@', '#', '$'.
* The corresponding [`DocumentTableSet`](../../documenttableset) object does not contain a [`DocumentTable`](../../documenttable) instance with the same name.

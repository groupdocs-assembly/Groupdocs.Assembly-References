## DocumentTable class

Обеспечивает доступ к данным единственной таблицы (или электронной таблицы), расположенной во внешнем документе, которые будут использоваться при сборке документа.

### Примечания

Для документов формата электронных таблиц экземпляр [`DocumentTable`](../documenttable) представляет один лист. Для документов других форматов экземпляр [`DocumentTable`](../documenttable) представляет одну таблицу.

Чтобы получить доступ к данным соответствующей таблицы при сборке документа, передайте экземпляр этого класса в качестве источника данных в одну из перегрузок [`DocumentAssembler`](../../groupdocs.assembly/documentassembler).AssembleDocument.

В шаблонных документах экземпляр [`DocumentTable`](../documenttable) следует рассматривать так же, как экземпляр DataTable. См. справочник синтаксиса шаблонов для получения дополнительной информации.

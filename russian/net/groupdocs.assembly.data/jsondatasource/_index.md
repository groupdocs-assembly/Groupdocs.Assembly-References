### Примечания

Чтобы получить доступ к данным соответствующего файла или потока при сборке документа, передайте экземпляр этого класса в качестве источника данных в одну из перегрузок метода [`DocumentAssembler`](../../groupdocs.assembly/documentassembler).AssembleDocument.

В шаблонных документах, если верхнеуровневый элемент JSON является массивом, экземпляр [`JsonDataSource`](../jsondatasource) следует рассматривать так же, как если бы это был экземпляр DataTable. Если верхнеуровневый элемент JSON является объектом, экземпляр [`JsonDataSource`](../jsondatasource) следует рассматривать так же, как если бы это был экземпляр DataRow. Для получения дополнительной информации см. справочник синтаксиса шаблонов (https://docs.groupdocs.com/display/assemblynet/Template+Syntax+-+Part+1+of+2#TemplateSyntax-Part1of2-UsingDataSources).

В шаблонных документах вы можете работать с типизированными значениями элементов JSON. Для удобства движок заменяет набор простых типов JSON следующим:

* `long?`
* `double?`
* `bool?`
* `DateTime?`
* `string`

Движок автоматически распознаёт значения дополнительных типов по их JSON‑представлениям.

Чтобы переопределить поведение загрузки JSON‑данных по умолчанию, инициализируйте и передайте экземпляр [`JsonDataLoadOptions`](../jsondataloadoptions) в конструктор этого класса.

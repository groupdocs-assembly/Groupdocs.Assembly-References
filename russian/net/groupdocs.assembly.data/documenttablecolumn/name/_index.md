## DocumentTableColumn.Name property

Получает или задаёт имя этого столбца, используемое для доступа к данным столбца в шаблонном документе, переданном в [`DocumentAssembler`](../../../groupdocs.assembly/documentassembler).

```csharp
public string Name { get; set; }
```

### Примечания

Если имя столбца читается из документа (см. [`FirstRowContainsColumnNames`](../../documenttableoptions/firstrowcontainscolumnnames)), оно автоматически корректируется, чтобы быть допустимым. Однако если имя столбца задаётся вручную через это свойство и является недопустимым, генерируется исключение.

Имя столбца считается допустимым, если выполнены следующие условия:

* The name is not empty.
* The name's first character is a letter or underscore.
* The rest of the name's characters are letters, underscores, digits, or the following characters: '@', '#', '$'.
* The corresponding [`DocumentTable`](../../documenttable) object does not contain a [`DocumentTableColumn`](../../documenttablecolumn) instance with the same name.

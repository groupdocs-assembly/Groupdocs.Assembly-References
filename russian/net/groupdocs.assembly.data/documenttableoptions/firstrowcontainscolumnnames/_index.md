## DocumentTableOptions.FirstRowContainsColumnNames property

Получает или задаёт значение, указывающее, следует ли получать имена столбцов из первой извлечённой строки таблицы документа. Значение по умолчанию — false.

```csharp
public bool FirstRowContainsColumnNames { get; set; }
```

### Примечания

Если имена столбцов не заданы для получения из первой извлечённой строки таблицы документа, вместо этого используются имена столбцов по умолчанию. Для документов формата Spreadsheet имена столбцов по умолчанию определяются как A, B, C, … Z, AA, AB и т.д. Для документов других форматов имена столбцов по умолчанию определяются как Column1, Column2, Column3 и т.д.

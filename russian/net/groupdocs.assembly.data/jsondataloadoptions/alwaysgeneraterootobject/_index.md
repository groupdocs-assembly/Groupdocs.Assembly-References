## JsonDataLoadOptions.AlwaysGenerateRootObject property

Получает или задает флаг, указывающий, будет ли сгенерированный источник данных всегда содержать объект для корневого элемента JSON. Если корневой элемент JSON содержит единственное сложное свойство, такой объект по умолчанию не создаётся.

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### Примечания

Значение по умолчанию — **false**.

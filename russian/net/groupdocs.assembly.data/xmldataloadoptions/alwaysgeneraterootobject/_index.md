## XmlDataLoadOptions.AlwaysGenerateRootObject property

Получает или задает флаг, указывающий, будет ли сгенерированный источник данных всегда содержать объект для корневого элемента XML. Если у корневого элемента XML нет атрибутов и все его дочерние элементы имеют одинаковые имена, такой объект по умолчанию не создаётся.

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### Примечания

Значение по умолчанию — **false**.

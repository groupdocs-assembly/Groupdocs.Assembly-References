## DocumentTableOptions.FirstRowContainsColumnNames property

Αποκτά ή ορίζει μια τιμή που υποδεικνύει εάν τα ονόματα των στηλών πρέπει να ληφθούν από την πρώτη εξαγόμενη γραμμή ενός πίνακα εγγράφου. Η προεπιλεγμένη τιμή είναι ψευδής.

```csharp
public bool FirstRowContainsColumnNames { get; set; }
```

### Παρατηρήσεις

Εάν τα ονόματα των στηλών δεν οριστούν να λαμβάνονται από την πρώτη εξαγόμενη γραμμή ενός πίνακα εγγράφου, χρησιμοποιούνται αντί αυτού τα προεπιλεγμένα ονόματα στηλών. Για έγγραφα μορφής Spreadsheet, τα προεπιλεγμένα ονόματα στηλών ορίζονται ως A, B, C, ... Z, AA, AB, κ.λπ. Για έγγραφα άλλων μορφών αρχείων, τα προεπιλεγμένα ονόματα στηλών ορίζονται ως Column1, Column2, Column3, κ.λπ.

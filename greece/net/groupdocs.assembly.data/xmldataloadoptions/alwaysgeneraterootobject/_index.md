## XmlDataLoadOptions.AlwaysGenerateRootObject property

Λαμβάνει ή ορίζει μια σημαία που υποδεικνύει εάν μια παραγόμενη πηγή δεδομένων θα περιέχει πάντα ένα αντικείμενο για ένα στοιχείο ρίζας XML. Εάν ένα στοιχείο ρίζας XML δεν έχει ιδιότητες και όλα τα στοιχεία-παιδιά του έχουν τα ίδια ονόματα, ένα τέτοιο αντικείμενο δεν δημιουργείται εξ ορισμού.

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### Παρατηρήσεις

Η προεπιλεγμένη τιμή είναι **false**.

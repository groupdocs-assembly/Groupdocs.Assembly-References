## JsonDataLoadOptions.AlwaysGenerateRootObject property

Λαμβάνει ή ορίζει μια σημαία που υποδεικνύει εάν μια παραγόμενη πηγή δεδομένων θα περιέχει πάντα ένα αντικείμενο για ένα στοιχείο ρίζας JSON. Εάν ένα στοιχείο ρίζας JSON περιέχει μια μόνο σύνθετη ιδιότητα, ένα τέτοιο αντικείμενο δεν δημιουργείται εξ ορισμού.

```csharp
public bool AlwaysGenerateRootObject { get; set; }
```

### Παρατηρήσεις

Η προεπιλεγμένη τιμή είναι **false**.

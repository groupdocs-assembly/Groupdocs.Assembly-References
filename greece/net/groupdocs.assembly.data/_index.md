Παρέχει κλάσεις για την πρόσβαση σε δεδομένα εξωτερικών εγγράφων που θα χρησιμοποιηθούν κατά τη συναρμολόγηση ενός εγγράφου.

| [DocumentTableCollection](./documenttablecollection) | Αντιπροσωπεύει μια συλλογή μόνο για ανάγνωση από αντικείμενα [`DocumentTable`](../groupdocs.assembly.data/documenttable) ενός συγκεκριμένου παραδείγματος [`DocumentTableSet`](../groupdocs.assembly.data/documenttableset). |
| [DocumentTableColumn](./documenttablecolumn) | Αντιπροσωπεύει μια μοναδική στήλη ενός συγκεκριμένου αντικειμένου [`DocumentTable`](../groupdocs.assembly.data/documenttable). |

| [DocumentTableSet](./documenttableset) | Παρέχει πρόσβαση σε δεδομένα πολλαπλών πινάκων (ή λογιστικών φύλλων) που βρίσκονται σε εξωτερικό έγγραφο και θα χρησιμοποιηθούν κατά τη συναρμολόγηση ενός εγγράφου. Επίσης, επιτρέπει τον ορισμό σχέσεων γονέα-παιδιού για τους πίνακες εγγράφου, απλοποιώντας έτσι την πρόσβαση σε σχετικά δεδομένα μέσα στα πρότυπα εγγράφων. |
| [JsonDataLoadOptions](./jsondataloadoptions) | Αντιπροσωπεύει επιλογές για την ανάλυση δεδομένων JSON. |

| [XmlDataLoadOptions](./xmldataloadoptions) | Αντιπροσωπεύει επιλογές για τη φόρτωση δεδομένων XML. |

## DocumentTableColumn.Type property

Λαμβάνει ή ορίζει τον τύπο των τιμών κελιών σε αυτή τη στήλη.

```csharp
public Type Type { get; set; }
```

### Παρατηρήσεις

Για έγγραφα μη-Spreadsheet μορφών αρχείου, ο αρχικός τύπος καθορίζεται πάντα αυτόματα ως string. Για έγγραφα μορφής Spreadsheet, ο αρχικός τύπος καθορίζεται αυτόματα ανάλογα με τις αντίστοιχες τιμές των κελιών.

Εάν τα κελιά μιας συγκεκριμένης στήλης Spreadsheet περιέχουν τιμές διαφορετικών τύπων, τότε ο αρχικός τύπος της στήλης επίσης καθορίζεται αυτόματα ως string.

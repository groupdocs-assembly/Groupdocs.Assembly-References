Παρέχει κλάσεις για τη δημιουργία εγγράφων σε δημοφιλείς μορφές αρχείων γραφείου, βασισμένες σε έγγραφα προτύπων και δεδομένα που προέρχονται από διάφορες πηγές, συμπεριλαμβανομένων βάσεων δεδομένων, XML, JSON, OData, αντικειμένων προσαρμοσμένων τύπων .NET και άλλων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [BarcodeSettings](./barcodesettings) | Αντιπροσωπεύει ένα σύνολο ρυθμίσεων που ελέγχουν τη δημιουργία barcode κατά τη συναρμολόγηση ενός εγγράφου. |
| [DataSourceInfo](./datasourceinfo) | Παρέχει πληροφορίες για ένα μοναδικό αντικείμενο πηγής δεδομένων που θα χρησιμοποιηθεί για τη συναρμολόγηση ενός εγγράφου από ένα πρότυπο. |
| [DocumentAssembler](./documentassembler) | Παρέχει διαδικασίες για τη συμπλήρωση εγγράφων προτύπων με δεδομένα και ένα σύνολο ρυθμίσεων για τον έλεγχο αυτών των διαδικασιών. |
| [KnownTypeSet](./knowntypeset) | Αντιπροσωπεύει ένα αταξινόμητο σύνολο (δηλαδή, μια συλλογή μοναδικών στοιχείων) που περιέχει αντικείμενα Type, των οποίων τα πλήρως ή μερικώς προσδιορισμένα ονόματα μπορούν να χρησιμοποιηθούν μέσα σε πρότυπα εγγράφων για την κλήση των στατικών μελών των αντίστοιχων τύπων, την εκτέλεση μετατροπών τύπων κ.λπ. |
| [License](./license) | Παρέχει μεθόδους για την αδειοδότηση του στοιχείου. |
| [LoadSaveOptions](./loadsaveoptions) | Καθορίζει πρόσθετες επιλογές για τη φόρτωση και αποθήκευση ενός εγγράφου που θα συναρμολογηθεί. |
| [Metered](./metered) | Παρέχει μεθόδους για εργασία με αδειοδότηση με μέτρηση. |

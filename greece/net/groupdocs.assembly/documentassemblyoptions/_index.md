## DocumentAssemblyOptions enumeration

Καθορίζει επιλογές που ελέγχουν τη συμπεριφορά του [`DocumentAssembler`](../documentassembler) κατά τη συναρμολόγηση ενός εγγράφου.

```csharp
[Flags]
public enum DocumentAssemblyOptions
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| None | `0` | Καθορίζει τις προεπιλεγμένες επιλογές. |
| AllowMissingMembers | `1` | Καθορίζει ότι τα ελλιπή μέλη αντικειμένου πρέπει να αντιμετωπίζονται ως κυριολεκτικά null από τον συναρμολογητή. Αυτή η επιλογή επηρεάζει μόνο την πρόσβαση σε μέλη αντικειμένου στιγμής (δηλαδή, μη-στατικά) και μεθόδους επέκτασης. Εάν αυτή η επιλογή δεν οριστεί, ο συναρμολογητής ρίχνει μια εξαίρεση όταν συναντά ένα ελλιπές μέλος αντικειμένου. |
| UpdateFieldsAndFormulas | `2` | Καθορίζει ότι τα πεδία των τελικών εγγράφων Επεξεργασίας Κειμένου και οι τύποι των τελικών εγγράφων Υπολογιστικού Φύλλου πρέπει να ενημερώνονται από τον συναρμολογητή. |
| RemoveEmptyParagraphs | `4` | Καθορίζει ότι ο συναρμολογητής πρέπει να αφαιρέσει τις παραγράφους που γίνονται κενές μετά την αφαίρεση ή αντικατάσταση των ετικετών σύνταξης προτύπου με κενές τιμές. |
| InlineErrorMessages | `8` | Καθορίζει ότι ο συναρμολογητής πρέπει να ενσωματώνει τα μηνύματα σφάλματος σύνταξης προτύπου στα έγγραφα εξόδου. Εάν αυτή η επιλογή δεν οριστεί, ο συναρμολογητής ρίχνει μια εξαίρεση όταν συναντά σφάλμα σύνταξης. |
| UseSpreadsheetDataTypes | `10` | Αφορά μόνο έγγραφα Spreadsheet. Καθορίζει ότι τα αποτελέσματα των αξιολογημένων εκφράσεων πρέπει να αντιστοιχίζονται στους αντίστοιχους τύπους δεδομένων Spreadsheet, κάτι που επίσης επηρεάζει την προεπιλεγμένη μορφοποίηση τους στα κελιά. Εάν αυτή η επιλογή δεν οριστεί, τα αποτελέσματα των εκφράσεων γράφονται πάντα ως συμβολοσειρές από τον συναρμολογητή. Αυτή η επιλογή δεν έχει καμία επίδραση όταν τα αποτελέσματα των εκφράσεων μορφοποιούνται χρησιμοποιώντας σύνταξη προτύπου - τα αποτελέσματα των εκφράσεων γράφονται πάντα ως συμβολοσειρές και σε αυτήν την περίπτωση. |

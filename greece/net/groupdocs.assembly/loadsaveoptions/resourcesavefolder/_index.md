## LoadSaveOptions.ResourceSaveFolder property

Λαμβάνει ή ορίζει μια διαδρομή σε φάκελο για την αποθήκευση εξωτερικών αρχείων πόρων ενώ ένα συναρμολογημένο έγγραφο που φορτώθηκε από μορφότυπο μη-HTML αποθηκεύεται σε HTML. Η προεπιλεγμένη τιμή είναι μια κενή συμβολοσειρά.

```csharp
public string ResourceSaveFolder { get; set; }
```

### Παρατηρήσεις

Από προεπιλογή, όταν αποθηκεύεται ένα συναρμολογημένο έγγραφο σε αρχείο HTML, τα εξωτερικά αρχεία πόρων αποθηκεύονται σε φάκελο που έχει το ίδιο όνομα με το αρχείο HTML χωρίς την επέκταση, προσθέτοντας το επίθημα \"_files\". Αυτός ο φάκελος βρίσκεται στον ίδιο φάκελο με το αρχείο HTML. Ωστόσο, αυτό δεν είναι δυνατό όταν αποθηκεύεται ένα συναρμολογημένο έγγραφο σε ροή HTML. Ορίστε αυτή την ιδιότητα για να καθορίσετε μια διαδρομή σε φάκελο για την αποθήκευση εξωτερικών αρχείων πόρων όταν αποθηκεύεται ένα συναρμολογημένο έγγραφο σε ροή HTML ή για να παρακάμψετε τον προεπιλεγμένο φάκελο όταν αποθηκεύεται ένα συναρμολογημένο έγγραφο σε αρχείο HTML.

Μια τιμή αυτής της ιδιότητας αγνοείται εάν ένα συναρμολογημένο έγγραφο που αποθηκεύεται σε HTML φορτώθηκε επίσης από HTML (τα εξωτερικά αρχεία πόρων δεν αποθηκεύονται και οι σύνδεσμοι προς αυτά δεν αλλάζουν).

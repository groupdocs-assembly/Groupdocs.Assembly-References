## BarcodeSettings.BaseXDimension property

Λαμβάνει ή ορίζει μια βασική διάσταση x, δηλαδή το μικρότερο πλάτος της μονάδας των γραμμών και κενών του barcode. Μετράται σε [`GraphicsUnit`](../graphicsunit).

```csharp
public float BaseXDimension { get; set; }
```

### Παρατηρήσεις

Όταν εφαρμόζεται κλιμάκωση barcode μέσω προτύπου, μια πραγματική διάσταση x υπολογίζεται με βάση τη βασική διάσταση x και έναν συντελεστή κλιμάκωσης.
